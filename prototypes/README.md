# PWA 设计原型

`acp-remote-pwa.html` 是 **ACP Remote Web/PWA 的设计原型**，用来在写实现之前把页面结构、状态与交互对齐。

## 它是什么

- 单文件 HTML，零外部资源（无 CDN、无字体、无图片），符合 `FRONTEND_DESIGN.md §4.5` 的 CSP 基线
- 用 hash 路由在四个页面之间切换，用右下角「原型控制台」切换各种状态与场景
- 数据是写死的假数据，**不连任何真实服务**

```text
#/pair            配对页（18 个状态：等待确认 / 已连接 / 各类阻断与失败）
#/dirs            目录页（目录为主角，每个目录最多 5 条会话 + 查看全部）
#/dir/<id>        目录详情（按月分档 + 搜索 + 状态筛选）
#/chat/<session>  对话页（左：同目录会话 / 中：对话流 / 右：变更文件）
```

## 它不是什么

- **不是产品代码**，不参与构建、不被任何 crate 打包，也没有测试
- **不是合同**。其中的设计结论尚未同步到 `docs/`，请以权威文档为准
- 原型里的 mock 数据、时间、指纹、会话标题都是编造的

## 已知与权威文档的差距（实施前必须先解决）

| 项 | 现状 | 说明 |
|---|---|---|
| 目录字段 | `SessionSummary` 没有 workspace 概念 | 目录页与新建会话都依赖它，需要加列 + schema + 文档 |
| 设备侧创建会话 | Sync v1 只有 Node Link 有 `session.create` | 需要新 feature、命令、scope |
| Agent 列表查询 | PWA 无从得知本机配置了哪些 Agent | 需要新增查询命令 |
| 目录路径下发 | 详情页显示完整路径，目录页显示尾段 | 与 `SECURITY_DESIGN.md §12.3`「不得经 wire 传输路径」冲突，待决定 |
| 移动端布局 | 只有桌面版 | `FRONTEND_DESIGN.md §9` 把响应式手机布局列为验收项 |

## 修改原型时的注意事项

浏览器"打开是空白"多数是**运行期**错误，`node --check` 只查语法。改动后至少确认：

1. 每条路由都能打开
2. 控制台里的每个下拉/开关都能切换
3. 抽屉、弹层的关闭路径（`Esc` / 点外部 / 关闭按钮）

如果条件允许，用最小 DOM 桩在 Node 里跑一遍脚本，比肉眼可靠。
