## 刷新按钮修复

原实现把「会话变更」的按钮固定禁用，`refreshFiles` 也直接返回。现改为协商会话历史后，通过既有 `session.read` 仅请求 `history`，去重合并最新记录，保留消息页、旧历史和分页位置；在途不重复派发，失败与不可用原因在文件栏显示。

验证：前端 `npm run check` 通过（1209 项测试及 Web 导出）；根合同检查通过；浏览器 100/100 通过。SF-1 新增实际点击刷新按钮并断言出站载荷为 `include: ["history"]`，使用真实页面/客户端和模拟主机，不代表真实 Agent 验收。
