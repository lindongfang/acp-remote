# 文件栏需求讨论

状态：需求与关键交互已确认；尚未形成完整实现规范，尚未开始产品代码实现。

## 已确认

- 对话页「变更文件」改名为「文件」，下方提供「全部文件 / Git 变更 / 会话变更」三个选项，默认选中「会话变更」。
- 三个选项均以当前会话工作目录为范围。
- 全部文件按文件夹层级浏览，默认展示隐藏文件与 Git 忽略文件，但始终隐藏 `.git` 内部目录；提供「隐藏忽略文件」按钮。用户已撤回此前展示 `.git` 的决定。
- Git 变更包括范围内已暂存、未暂存和未跟踪的新增文件，不限于当前会话造成的修改。
- 会话变更只包含当前会话中 Agent 修改过的文件，同路径合并为一项，展开后按时间查看历次修改；不拼接累计差异，不混入其他会话或手动修改。
- 首版只读：全部文件打开当前内容；Git 变更打开未提交差异；会话变更打开本会话修改记录。不提供编辑。
- 点击文件后，在中间对话区展示相应内容；文件视图右上角提供关闭按钮，关闭后恢复对话。右侧文件列表保留，便于继续选择文件。不采用文件页签方案。
- 已打开文件 A 时点击文件 B，直接替换中间文件内容，不增加多个页签。
- 关闭文件后恢复原来的对话滚动位置与输入草稿；查看文件期间 Agent 继续运行。
- 手机窄屏点击文件后直接展示文件内容，关闭后返回文件列表并保留列表位置。
- Git 差异默认比较上次提交与当前文件状态，合并已暂存和未暂存改动；新增文件显示全部内容，删除文件显示删除前的内容。
- 工作目录不属于 Git 仓库时，保留「Git 变更」选项并显示「此目录不是 Git 仓库」，「隐藏忽略文件」按钮不可用。
- 文本预览内容，常见图片提供预览，其他二进制文件提供基本信息和下载入口；大文件限制预览大小并明确提示。
- 首版新增文件浏览与 Git 查询仅支持本节点直接管理的会话。远程导入会话保留已有会话变更，另外两项明确提示暂不支持，不扩展跨节点协议。
- 进入文件视图时刷新，提供手动刷新；收到当前会话文件修改事件时自动刷新，不持续监控整个磁盘目录。
- 指向当前会话工作目录外的文件链接只展示，不允许打开；浏览、预览和下载均不得越出当前会话工作目录。
