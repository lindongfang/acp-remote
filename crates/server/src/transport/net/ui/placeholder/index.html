这是占位入口，不是真实前端

本二进制在构建时没有找到真实前端产物（clients/app/dist/index.html）， 因此嵌入的是这份占位页面。它的作用是让没有前端产物的环境（CI 的 Rust 作业、 尚未构建前端的开发机）也能编译并运行 cargo test。

发布构建不会提供这个页面：Daemon 在发布构建（daemon start）里检测到占位 入口时会失败关闭，并提示先构建前端。因此看到这个页面说明当前是 debug 构建。

要拿到真实页面：在 clients/app 运行 npm run export:web 产出 dist/，再重新构建 Daemon（构建脚本会在下一次构建时改选真实产物）。

占位判定不依赖这段文字：嵌入资源表在编译期由 crates/server/build.rs 打上标记， Daemon 读的是那个标记。
