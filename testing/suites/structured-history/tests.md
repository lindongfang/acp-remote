## Cases
### CL-012 恢复重放旧消息

- 用例级别：L5
- 操作步骤：恢复时重放旧条目及重复正文的不同条目，分别有可靠来源关联和无跨加载 ID；混入实时输出及旧代际迟到响应。
- 预期结果：旧历史不成新回复；可靠关联才衔接，无依据重建/分开并说明限制，不按文字/摘要去重，不让旧代际覆盖新视图。

### CL-023 工具晚完成

- 用例级别：L5
- 操作步骤：在实际版本与可证明的同一来源/身份内，依原生顺序提供工具 T 开始、后续文字 A/B、T 的进度更新、文字 C、T 的再次更新及最终状态/结果；逐次比较 T 首次位置和身份、A/B/C 的正文及相对顺序、条目数量，再重放重读。另给来源不足以证明同一工具的对照。
- 预期结果：每次进度、状态及最终结果都更新首次出现位置的同一 T；A/B/C 正文与原相对顺序保持，不把 T 移到完成处或列表末尾、不按类型重排、不追加同一工具的重复完成条目。有可靠来源关联才更新或避免重读重复；来源不足时明确限制、不猜测合并，也不复制为新回复。

### CL-024 未知结构载荷

- 用例级别：L5
- 操作步骤：实时及重放提供未知结构/扩展、必要原始字段和支持结构；内容超过旧单对象/实体预算，读取安全视图与惰性原始数据。
- 预期结果：保留实际结构、来源和字段，未知明确显示限制，不静默降文本或执行主动内容，不因旧内容预算截断；真实分配/协议失败如实报告。

### CL-027 实时尾部丢失

- 用例级别：L5
- 操作步骤：已有原生历史与实时尾部时重启节点，确认内存视图丢失；让原生分别返回完整、压缩后历史及读取失败。
- 预期结果：从 Harness 重建实际可读内容，原生不再保留的尾部不补造；错误明确，不从平台管理记录恢复聊天，不宣称显示即已保存。

### CL-042 正常输出隐藏保存状态但内部保真

- 用例级别：L5
- 操作步骤：当前连接已有输出且无后续增量，首次订阅/重连/刷新读取；交错旧新读取响应，对照实际展示失败，不注入人为容量淘汰。
- 预期结果：首开即展示节点已有输出，正常不显示保存进度/提交版本；无旧预算截断或淘汰，旧响应不回退视图；真实失败报告原因，缓存不成为永久档案。

### CL-050 部分中断解析失败及超预算不伪完整

- 用例级别：L5
- 操作步骤：分别在重放完成前断线、注入不合法结构、取消读取及实际来源不能继续；另提供超过旧32MiB帧/16MiB视图但当前协议可处理的合法内容；连接健康时并发输入审批，对照连接失效。
- 预期结果：真实中断/解析失败不伪完整，不重发输入；合法大内容不因旧预算失败。展示失败本身不取消工作或有效审批，连接失效按真实生命周期。标题“超预算”为历史语义，不再作为拒绝依据。

### CL-051 无跨加载稳定标识时重建代际而不按正文去重

- 用例级别：L5
- 操作步骤：两次重放只有各自可靠临时位置且含相同正文的不同项，两客户端并发查看，延迟旧响应并混入可关联/不可关联实时数据。
- 预期结果：同目标协调在途加载，新代际重建失效旧视图，旧响应不覆盖；不按正文/摘要去重，无法衔接说明限制。

### CL-061 原生会话发现不依赖平台输入绑定

- 用例级别：L5
- 操作步骤：外部客户端在授权来源创建会话，节点刷新列表并按 ID 查看；对照无列表但可按 ID 读取，及越权 ID。
- 预期结果：可发现/读取授权原生内容而不导入聊天或先执行接管；无列表说明限制不扫描私有目录，列表/读取/执行权限分开校验。

### CL-062 清缓存与原生删改后的权威重建

- 用例级别：L5
- 操作步骤：已看过历史后清节点缓存/重启，原生分别保留、压缩/删改及不再可用；检查新视图及平台数据库写入。
- 预期结果：只以原生实际结果展示，不回填旧全文、命令或审计；缓存可丢弃，新入口无永久聊天正文/工具正文/历史附件写入。

### CL-063 外部更新刷新及旧视图错误标记

- 用例级别：L5
- 操作步骤：外部向同一原生会话追加内容，分别显式刷新/重开/重连/再接管；读取失败时保留旧缓存对照。
- 预期结果：重新校验来源并读取更新，外部输入不补造平台 Command/Run/审批；失败明确且旧缓存标旧，不假称所有外部操作实时同步。

### CL-064 节点共享视图与释放换代失效

- 用例级别：L5
- 操作步骤：同连接有已接收缓存时刷新/断网/换可信设备，跨旧缓存容量阈值后核对共享内容；撤销一端，再显式释放/连接换代/重启后分别在有重放和无重放条件查看。
- 预期结果：浏览器变化不清节点视图，授权客户端共享完整已接收内容，无旧容量淘汰；撤销端禁止读取。生命周期结束旧视图可失效，有重放按原生重建，无重放明显提示历史不完整/旧缓存无法补回，不造永久副本。

### CL-070 实时重放不可信内容安全呈现

- 用例级别：L5
- 操作步骤：在浏览器实时及重放注入合成脚本/HTML事件/主动SVG/终端控制/未知扩展、标题与要求自动批准的文本；命令/路径/审批描述加入双向与零宽字符，监测脚本/管理调用。
- 预期结果：允许字段安全显示或占位，原始结构惰性保留不执行；零管理副作用/自动审批，误导字符效果显露或移除，真实审批目标来自节点结构字段。

### CL-071 附件链接与资源读取独立授权

- 用例级别：L5
- 操作步骤：渲染远程媒体及隐藏实际目标链接，用户显式加载回环/私网/Tailscale/重定向至私网、越根文件、主动 HTML/SVG、非HTTP协议及超预算附件；服务端记录访问并用独立身份测试。
- 预期结果：默认无自动抓取/外开/凭据携带，实际入口逐次授权及校验最终目标/根/类型/预算，非法拒绝；未实现安全读取入口明确不支持，主动内容不获同源管理权限，外部处理器须支持且完整目标确认。

### CL-085 真实查看外部更新与无 Run 归属

- 用例级别：L6
- 操作步骤：在真实已准入 Harness/Windows/Web 的专用来源，从外部客户端建/更新会话，平台发现或按 ID 查看及标准重放；按真实可用能力观察无Run前台/加载或后台审批、有效请求在前台结束后处理，刷新/换端/释放重看。
- 预期结果：正常原生读写/审批边界有真实来源与调用证据，不造平台输入，缓存与真实权限正确；真实程序未产生的可选活动分支未执行，合同替身不能补签。
