# sync-workspace-mkdir Specification

## Purpose
定义已认证设备在主机目录选择过程中独立创建一层目录的可观察行为。使用户可以先在真实文件系统中逐层建好目录、确认结果，再选择工作目录或取消会话创建，并使重复请求、断线与崩溃不会被误报为成功或产生隐式重试。

## Requirements

### Requirement: 独立建目录命令与兼容前提

系统 SHALL 提供只经 Sync 接受的 mutation `workspace.mkdir`，受 `core.workspace-mkdir.v1` 门控。未认证、已撤销或未协商该 feature 时 MUST 在任何文件系统访问之前拒绝。该命令 MUST NOT 接受 Node Link 请求，不新增设备 scope；既有只读目录浏览和会话创建命令 SHALL 保持原语义。

#### Scenario: 已认证设备独立新建

- **WHEN** 已认证设备协商了独立建目录 feature 并提交有效请求
- **THEN** 系统受理该命令并执行主机目录创建，不创建会话、不启动 Agent

#### Scenario: 缺少前提

- **WHEN** 请求未认证、设备已撤销、未协商 feature 或来自 Node Link
- **THEN** 明确拒绝且不读取或修改文件系统

### Requirement: 当前父目录与单层名字校验

请求 SHALL 只含 `parentPath` 和 `name`：父路径为既有绝对目录，名字为一个非空组件，MUST NOT 是 `.`、`..`，MUST NOT 含路径分隔符、卷标冒号或空字节。字段超长、多余字段与非法形状 SHALL 在文件系统访问前以参数类错误拒绝。创建 MUST 只发生在指定父层，MUST NOT 回退至替代位置、覆盖既有文件或目录。

#### Scenario: 名字含上级或分隔符

- **WHEN** 名字是 `..`、含 `/` 或 `\`，或父路径不是绝对路径
- **THEN** 返回参数类失败，不触碰文件系统

#### Scenario: 父层不可达或目标已存在

- **WHEN** 父目录不存在、不可写、已变为文件，或目标已经存在
- **THEN** 返回可见失败，不覆盖既有对象、不回退到其它目录，也不创建会话

### Requirement: 持久受理与命令终态

命令 SHALL 携带稳定 `requestId`。系统 MUST 先持久化受理与请求指纹，再执行目录创建；只有文件系统成功且命令成功终态已持久化，才可返回或广播完成。相同主体和请求标识的重复请求 MUST 回到同一受理/终态，不二次执行；标识相同但内容改变 MUST 返回幂等冲突。受理后崩溃而无法确认结果时 MUST 终结为 `uncertain`，MUST NOT 自动重做文件系统副作用。

#### Scenario: 同一请求重复投递

- **WHEN** 同一建目录请求因网络重试被投递两次
- **THEN** 最多执行一次创建，重试读取原来的命令状态

#### Scenario: 崩溃发生在文件系统与终态提交之间

- **WHEN** 系统无法确认受理的目录创建是否完成
- **THEN** 对该命令呈现结果不确定，不宣称未创建，也不擅自重试或删除目录

### Requirement: 成功结果与目录生命周期

成功终态 SHALL 返回 `{ created: true }`，路径仍通过只读浏览结果获取。命令终态事件、错误、日志和审计 MUST NOT 包含用户路径或目录名正文。目录创建本身 MUST NOT 登记 workspace；用户关闭选择器、取消创建会话或 Agent 启动失败 MUST NOT 删除已经创建的目录。

#### Scenario: 完成后浏览父层

- **WHEN** 建目录命令完成后重新浏览同一父层
- **THEN** 结果包含实际创建的目录；它可以被进入并作为下一次新建的父层

#### Scenario: 取消后目录仍存在

- **WHEN** 用户成功新建目录后取消目录选择或会话创建
- **THEN** 主机上的目录保留，且没有新会话或 Agent 进程
