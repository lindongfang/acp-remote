# ACP Remote

本地优先的 ACP 中转站：一个节点直接管理本机 Agent，也可以通过 Node Link 导入其他节点导出的 Agent。

本文件只钉「在本仓库里必须唯一」的词。它不定义行为、不写实现细节：协议形状以 `docs/` 的权威文档为准，crate 职责以 `docs/MODULE_ARCHITECTURE.md` 为准。一个词只有在本仓库里被两处以上各自复述、且含义必须唯一时才收进来。

## Language

### 会话与任务

**对话发生顺序**：
同一会话中用户输入与 Agent 思考、工具调用、回复实际出现的先后关系；这些内容可以交替出现，不按内容类型预设排列顺序。
_Avoid_: 思考优先、工具优先、按类型排序

**会话摘要**：
会话的精简概况，包含标题、状态、Agent、来源及更新时间等信息；不是对聊天正文生成的文字总结。
_Avoid_: 标题、聊天总结、内容摘要

**连接资料**：
用于识别、信任和连接另一节点的资料，包括节点身份、公钥、地址及本机信任决定；不包含对方的会话资料、命令状态或事件进度。
_Avoid_: 会话缓存、远程目录、交付记录

**来源位置**：
某个会话在所属 Owner 事件历史中的位置，用于指出从哪里继续读取；区别于当前节点自身日志的位置。
_Avoid_: Access 本地序号、已读位置

**Agent 标题**：
由 Agent 提供的会话名称，区别于用户自行设置的名称。
_Avoid_: 自定义标题、用户昵称

**自定义标题**：
用户为会话设置的共享名称，对访问同一会话的各设备生效，展示优先级高于 Agent 标题。
_Avoid_: 设备昵称、本地别名、Agent 标题

**有效标题**：
当前用于展示和搜索的会话名称，优先采用自定义标题，其次采用 Agent 标题；两者都没有时显示“未命名会话”。
_Avoid_: 原始标题、自动生成标题

**会话**：
可持续返回交流的上下文，承载多轮任务及其历史；某一轮完成、失败或取消不表示会话永久结束。
_Avoid_: 单轮任务、Agent 进程、页面连接

**会话准备**（历史术语，已被 ADR-0016 取代）：
曾指提交首条消息前临时准备 Agent、工作目录和输入的阶段，当时尚不是已持久保存的会话。自 2026-10-26（`session-create-and-empty-cleanup`）起它不再是目标概念：Web 新建直接调用 `session.create`，创建即持久化，首条消息之前会话就已存在（见 [docs/INITIAL_DESIGN.md](../docs/INITIAL_DESIGN.md) §3.7、[ADR-0016](adr/0016-session-create-and-empty-cleanup.md)）。读旧设计文档时该词只表示「当前版本已退役的临时阶段」，不表示任何现行行为，也不得用来描述已创建但尚未发送消息的会话。
_Avoid_: 已保存的待开始会话、已回收会话、恢复失败的会话

**任务轮次**：
会话中一次已接受输入所对应的执行单元，具有独立的进展与最终结果。
_Avoid_: 会话、单次工具调用、命令受理结果

**会话主状态**：
会话当前的活跃程度，仅分为空闲、运行中与待处理；不表达任务是否成功或连接是否可用。
_Avoid_: 任务结果、连接状态、会话终态

**空闲**：
会话没有有效未解决交互，也没有未结束任务的状态。
_Avoid_: 已关闭、已成功、Agent 在线

**运行中**：
会话没有有效未解决交互，但存在未结束任务的状态，包含任务已接受并排队的情况。
_Avoid_: 正在输出、进程存活

**待处理**：
会话存在有效未解决的授权或补充信息请求的状态，即使其他工作仍在执行也属于待处理。
_Avoid_: 未读消息、排队中、普通回复提问

### 会话生命周期目标术语（合同已冻结；实现尚未落地）

本节记录已确认的目标用语。自 2026-10-22（`session-activation-lifecycle` WP1）起，feature `core.local-session-lifecycle.v1`、Sync `session.resume`、查看控制帧与 `localActivity` 的 wire/端口/配置合同已冻结（见 `docs/SYNC_PROTOCOL.md` §9.8/§11.8、`docs/CORE_PORTS_AND_STORAGE.md` §3.3/§5.10）；实现待 WP2–WP5。现行 `sessionSummary.state` 的三态定义与取值**未变**，本机活跃是独立的可选字段，不是第四种主状态。

**活跃**：
会话没有有效未解决交互，且正在执行或排队任务，或已激活且尚未确认释放会话运行资源的状态；不表示 Agent 正在输出，也不单独保证此刻可发送。
_Avoid_: 运行中、正在生成、页面在线

**会话资源回收**：
释放会话用于继续交互的运行资源，保留会话身份和历史；区别于删除会话或结束其他会话。
_Avoid_: 删除连接、删除会话、清空历史

**会话删除**：
移除正式会话记录及其可恢复历史，使会话不再作为可继续交互的资源存在；区别于仅释放运行资源的会话资源回收。
_Avoid_: 会话注销、关闭 Agent、资源回收

**会话注销**（非规范用语）：
已停止使用的口语；必须根据实际结果改写为“会话资源回收”或“会话删除”，不能继续作为一个含义可变的状态词。
_Avoid_: 资源回收、会话删除、关闭会话

**会话内容**：
会话中已被正式保存、可从历史恢复的用户或 Agent 消息、任务轮次、工具调用、终端记录、结构化历史条目与待处理交互；标题、模式、配置和正式会话记录本身不构成会话内容。
_Avoid_: 草稿、未提交附件、设置

**空会话**：
已经正式创建、但从未产生会话内容的会话；区别于浏览器草稿和未提交输入（准备式新建已由 [ADR-0016](adr/0016-session-create-and-empty-cleanup.md) 取代，不再是目标概念）。
_Avoid_: 准备、草稿会话、新会话页面

**激活**：
让一个已有会话重新具备可继续交流的运行资源与 Agent 会话身份；已可用时复用，不可用时恢复原身份，绝不通过新建会话或重发历史冒充成功。
_Avoid_: 打开页面、新建会话、重连

**保留期**：
最后一个保护条件（查看者、未结束任务、有效待处理交互、停止未确认的执行）消失后，会话保持运行资源不被回收的时长，默认 30 分钟；任一条件重新出现即取消计时。页面阅读与网络心跳不延长它。
_Avoid_: 缓存时间、连接超时、会话有效期

**查看租约**：
某个已认证连接当前正在查看某会话的有界声明（默认 30 秒，可见页面每 10 秒续租）；只存在于内存，离页、断开或撤销即失效，心跳不续租。
_Avoid_: 在线状态、登录态、订阅

**资源代**：
一次会话运行资源建立或恢复的代号；回收、关闭失败与重新恢复都会换新代，用来拒绝旧代事件或旧命令结果绑定到新资源。
_Avoid_: 会话版本、进程号、连接代

### 准备与首次提交（历史术语；已由 ADR-0016 取代，随 v19 删除）

> **本节全部术语已退役，不是现行行为。** 它们记录 `web-session-preparation`（2026-10-22 起冻结、WP2 曾落地核心与存储）那套「准备（临时）→ 首发（正式）」的新建方式。2026-10-26 的 `session-create-and-empty-cleanup`（见 [ADR-0016](adr/0016-session-create-and-empty-cleanup.md)）已用「直接 `session.create`、创建即持久化」取代它：feature `core.session-preparation.v1`、准备控制帧、`session.start`、准备凭据与 `owned_first_submission` 都在 v19 迁移中删除（storage 侧见 [docs/CORE_PORTS_AND_STORAGE.md](../docs/CORE_PORTS_AND_STORAGE.md) §13）。下面各条只为读懂历史文档与旧分支而保留，**不得**用来描述现行系统；现行目标用语是「空会话」「保留期」「会话删除」与「激活」。

**准备（preparation，历史术语）**：
Web 新建会话在首条消息提交前的**临时**阶段：节点已分配最终 `sessionId`、可以建立临时 Agent 端点取得真实模式与配置，但尚未持久化会话记录；准备不进入目录、快照或命令历史。
_Avoid_: 草稿会话、已创建会话、空会话恢复

**准备凭据（receipt，历史术语）**：
节点签发的归属证明，绑定 `sessionId`、设备、标签页、Agent、目录与存储代；它**不是**登录凭证或 bearer token，不授予任何权限，只用于恢复/操作这一次准备。
_Avoid_: 登录令牌、会话 token、cookie

**首次提交（first submission，历史术语）**：
把完整首条输入（正文、附件清单、模式/配置）连同准备 ID 一次性正式受理的动作（`session.start` 的 `kind: initial`）；它是唯一产生正式会话记录与首条消息的入口。
_Avoid_: 发送、第一次 prompt、占位消息

**派发围栏（dispatch fence，历史术语）**：
调用 Agent 之前必须先提交的持久标记（`dispatch_started`）；提交后崩溃只能得到 `uncertain`，不能自动重发。围栏未提交时可证明未派发，才允许显式继续。
_Avoid_: 锁、超时、重试计数

**提交（commit，首条语境，历史术语）**：
首次受理事务落地——会话、目录归属、完整首条输入、稳定消息/请求身份与附件正式引用在同一事务写入。它表示「已保存」，**不**表示 Agent 已开始执行。
_Avoid_: 已完成、已发送、已派发

**失效（`stale`，历史术语）**：
准备资源代或租约已不再有效（运行期重启/代变化/已释放）的结果，只来自 `configure`/`renew`/`release` 与附件开始；`restore` 对有效凭据不会返回它。
_Avoid_: 过期登录、会话不存在

**存储重建（`store_rebuilt`，历史术语）**：
节点存储被整体替换，导致凭据里的存储代与当前不一致；旧准备材料作废、不可重试，客户端丢弃凭据后回目录重新分配。
_Avoid_: 数据损坏、会话删除

### 对话输入

**上传附件**：
用户从当前设备选择并将内容交给会话的文件，包括图片、已有音频和其他文件。
_Avoid_: 工作目录文件引用、外部链接

**工作目录文件引用**：
用户在消息中指定当前会话工作目录内的已有文件，区别于从当前设备上传新的文件内容。
_Avoid_: 上传附件、任意主机路径

**外部链接**：
消息中的外部资源地址；展示这个地址本身不代表已取得或已向 Agent 提供目标内容。
_Avoid_: 已上传附件、已读取资源

### 会话文件视图

**文件列表刷新**：
重新取得当前文件栏来源所展示的工作目录内容，区别于替换正在阅读的文件正文或 Git 差异。
_Avoid_: 文件实时同步、会话变更同步、正文刷新

**全部文件**：
当前会话工作目录内的文件集合，包含隐藏文件与 Git 忽略文件，但排除 `.git` 内部目录，按文件夹层级浏览。
_Avoid_: 全机文件、全部变更

**Git 变更**：
当前会话工作目录范围内尚未提交的文件集合，包括已暂存、未暂存和未跟踪的新增文件；修改可能来自当前会话、其他会话或人工操作，不表示当前会话独占这些改动。
_Avoid_: 会话变更、当前会话改动

**会话变更（已移除的文件栏来源）**：
历史术语。曾指文件栏中以当前会话的 `file.changed` 记录按路径归并的第三个来源；2026-10-20 由变更 `remove-session-file-changes` 从文件栏移除，现行文件来源只有「全部文件」和「Git 变更」。它不再表示任何现行界面来源，也不得用来描述 Git 变更或对话时间线中的单条工具差异。
_Avoid_: 现行文件来源、Git 变更、会话独占改动

### 命令与终态

**受理（`accepted`）**：
命令已被持久化接受，**可能已经产生副作用**；带受理时间（`acceptedAt`）。
_Avoid_: 成功、已完成、开始执行

**拒收（`rejected`）**：
未产生任何业务副作用，因此既没有受理时间也没有终态。
_Avoid_: 失败、出错

**终态**：
`completed` / `failed` / `uncertain` 三者之一；已受理的命令只能经持久化的事件到达终态，不能靠接口的返回时机推断。
_Avoid_: 结果、结束、完成

**说不清（`uncertain`）**：
已受理但无法证明结果；绝不自动重试，要重做必须换新的请求标识。
_Avoid_: 未知、超时、失败

### 配对与身份

**配对码（pairing code）**：
网页入口使用的一次性字符码，用于取回某次配对的绑定材料与配对秘密。
_Avoid_: 短码、秘钥、验证码、PIN

**配对秘密（pairing secret）**：
某次配对的一次性秘密，用于认领与状态查询的证明；只在内存中存在。
_Avoid_: 密钥、配对码

**扫码取回凭据（scan retrieval credential）**：
设备二维码里携带的一次性凭据，用于在配对仍可认领时取回该次配对的完整资料；它独立于配对码与配对秘密，不承担认领或状态查询的证明，认领、拒绝、失效、过期或重启后不得继续使用。
_Avoid_: 配对码、配对秘密、token、密钥

### 幂等与写入

**幂等键**：
`(actor, requestId)`；同键重发必须返回首次结果，不得二次派发。
_Avoid_: 令牌、去重号、事务号

**权威写入者**：
某一份状态唯一被允许写它的那个角色，别处只能读或发请求。
_Avoid_: 主节点、源端、owner

### 网络与部署

**绑定地址（bind address）**：
Daemon 在本机哪些网卡或 IP 上接受连接；它决定暴露面，但不是访问授权。
_Avoid_: IP 白名单、监听白名单、允许访问的 IP

**绑定端口（bind port）**：
Daemon 在本机接受连接的端口。
_Avoid_: 对外端口、服务端口

**对外身份（canonical public origin）**：
外部访问 Daemon 时使用的权威 origin，用于 Host/Origin 校验、配对地址与设备身份绑定。
_Avoid_: 公网 IP、访问地址、对外端口

**对外端口（public port）**：
外部访问地址里的端口；在反向代理形态下与绑定端口不同。
_Avoid_: 监听端口

### 路径与目录

**工作区别名**：
只在本机登记空间内解析的符号名；原始路径永不进 wire。
_Avoid_: 目录名、路径、workspace 名

**规范化路径**：
本机 `canonicalize` 的结果，仓库内部的权威取值（Windows 上带 verbatim 前缀）；它属于内部表述，交给外部进程时要另行表述。
_Avoid_: 绝对路径、真实路径、full path
