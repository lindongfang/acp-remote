# Harness Control Plane

本术语表区分原生会话、平台管理与连接生命周期中的对象。行为约束以对应规格为准。

## Language

**启动配置（HarnessDefinition）**：
描述如何启动和接入一个 Harness 的配置，与其引用的接入来源分别存在。
_Avoid_: 将每份启动配置都视为独立接入来源

**接入来源（NativeScope，原称原生存储范围）**：
平台显式配置的 Harness 会话来源命名空间，同一来源可以由多个启动入口引用。
_Avoid_: 将来源身份当作已自动验证的物理存储或账户身份

**原生会话身份**：
接入来源及其中的原生会话标识共同表达的会话身份，同一来源内不随启动入口或连接变化。
_Avoid_: 仅用会话短 ID 表示全局身份

**Harness 连接代际**：
节点与 Harness 一次有效协议连接的生命周期，与浏览器连接及原生会话身份分别存在。
_Avoid_: 不加区分地称为当前连接

**原生操作上下文**：
具有真实来源、目标和有效生命周期的原生操作归属，可以是加载、恢复或一次输入执行。
_Avoid_: 将所有原生操作称为聊天轮次或 Run

**平台 Run**：
平台受理一次用户输入后跟踪的执行过程，不代表查看、加载或外部客户端发起的对话。
_Avoid_: 为读取或审批凭空建立执行轮次

**当前连接视图**：
节点在某个 Harness 连接代际内提供的有界、非持久化内容视图，可以由多个有权客户端共享。
_Avoid_: 将浏览器断连等同于原生会话结束

**能力准入**：
当前操作满足平台协议实现、对端协议依据、来源和权限等要求时的可用性判断，与某个程序版本是否已有实测报告分别表达。
_Avoid_: 用受测版本白名单替代运行时准入

**重放兼容**：
平台按已实现的 ACP 版本及实际能力接收标准历史重放，流式重建有界、可丢弃视图后向页面分页；不要求 Harness 原生按轮次分页，不包含厂商专用读取器。
_Avoid_: 将页面分页称为原生分页，或将重放缓存称为平台聊天档案

**重放读取代际**：
一次协调后的历史重放及其视图续读范围；连接内可有多次重放，临时位置及游标只在对应代际有效，不冒充跨重启原生身份。
_Avoid_: 将重放完成当作新一轮执行完成
