# Harness Control Plane

本术语表区分原生会话、平台管理与连接生命周期中的对象。行为约束以对应规格为准。

## Language

**启动配置（HarnessDefinition）**：
描述如何启动和接入一个 Harness 的配置，与其引用的接入来源分别存在。
_Avoid_: 将每份启动配置视为独立接入来源

**接入来源（NativeScope，原称原生存储范围）**：
平台显式配置的 Harness 会话来源命名空间，同一来源可以由多个启动入口引用。
_Avoid_: 将来源身份当作已自动验证的物理存储或账户身份

**原生会话身份**：
接入来源及其中的原生会话标识共同表达的会话身份，同一来源内不随启动入口或连接变化。
_Avoid_: 仅用会话短 ID 表示全局身份

**Harness 连接代际**：
节点与 Harness 一次有效协议连接的生命周期，与浏览器连接及原生会话身份分别存在。
_Avoid_: 不加区分地称为当前连接

**原生操作上下文**：
具有真实来源、目标和有效生命周期的原生操作归属，可以是加载、恢复或一次输入执行。
_Avoid_: 将所有原生操作称为聊天轮次或 Run

**平台 Run**：
平台派发一次用户输入后跟踪的执行过程，与尚未发送的队列项分别存在，不代表查看、加载或外部输入。
_Avoid_: 为读取或审批凭空建立执行轮次

**当前连接视图**：
节点在某个 Harness 连接代际内提供的实时内容视图，可以由多个有权客户端共享查看；跨回收与重启的离线展示由展示快照库在有效期内承接。
_Avoid_: 将浏览器断连等同于原生会话结束

**展示快照库（TranscriptCache）**：
与核心管理控制库物理隔离的平台自有持久化结构化展示缓存，默认按 30 天滑动有效期（按实际写入与原生同步刷新）及 10 GiB 总磁盘上限淘汰，仅用于 UI 离线回看、轮次分页与轻量恢复后的历史衔接，绝不拼回文本冒充原生模型上下文，也不解析厂商私有会话文件。
_Avoid_: 将展示快照库称为永久聊天档案、管理事实备份或模型上下文来源

**能力准入**：
当前操作满足平台协议实现、对端协议依据、来源和权限等要求时的可用性判断，与某个程序版本是否已有实测报告分别表达。
_Avoid_: 用受测版本白名单替代运行时准入

**重放兼容**：
平台按已实现的 ACP 版本及实际能力接收标准历史重放，更新展示视图及展示快照库后向页面提供可证明的分页；不要求 Harness 原生按轮次分页，不包含厂商专用读取器。
_Avoid_: 将页面分页称为原生分页，或将重放缓存称为永久聊天档案

**重放读取代际**：
一次协调后的历史重放或快照代际及其视图续读范围；连接内可有多次原生同步重放，临时位置及游标只在对应代际有效，不冒充跨重启原生身份。
_Avoid_: 将重放完成当作新一轮执行完成

**会话控制权接管（SessionControlTakeover）**：
主会话（根执行树）在活跃加载期内对单个受信客户端的独占写控制状态（支持顶号式显式接管并递增 `controlEpoch`），其余受信客户端对该会话保持只读观察；随显式释放控制权、控制端被撤销、主会话资源释放或节点重启自动归零。与节点级客户端信任（`client-trust`）及外部原生会话纳管（`native-session-import`）分别存在。
_Avoid_: 将单会话控制权接管混称为设备配对授权，或误作平台对外部 CLI 会话的纳管

**节点输入队列**：
节点已受理、尚未向 Harness 发送的会话输入集合，由所有受信客户端共享只读查看、仅允许当前持有该主会话控制权的客户端写入与调整（编辑、取消、置顶、继续恢复），与原生已插入消息及活动 Run 分别存在。
_Avoid_: 浏览器独立发送队列、已经开始的 Run、任意未接管只读设备直接改写队列

**节点受理授权**：
节点接受某次管理操作时确认的操作者、会话控制权代际（若适用）、目标及内容依据；节点接管已受理操作的后续派发与交付责任，与操作者之后的在线、控制权让渡或权限撤销状态分别存在。
_Avoid_: 每次工具执行都已获授权、交付时再次要求原提交者在线或仍持有控制权
