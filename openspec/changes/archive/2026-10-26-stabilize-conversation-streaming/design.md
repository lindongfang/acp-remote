# Design

## Context

动机与用户选择见 proposal.md。现有 `ConversationStream` 在每次提交后无依赖运行布局 effect，读滚动几何并遍历展开块；还存在尺寸观察与同步滚动事件，尺寸判重目前只避免重复写滚动，未避免重复测量。`ConversationTimeline` 每次重新分组并渲染全部条目；`formatEntryTime` 每次构造 `Intl.DateTimeFormat`；`Markdown` 缓存词法结果但仍为所有可见块重新创建视图。页面由 `ClientStore` 构建模型，简单套 `memo` 不能保证收益。

浏览器已捕捉流式收尾时稳定消息标识对应节点的移除、用户输入本地回显的再次出现与滚动回跳。动态分组 key、流式/读取交接及本地回显消除均是必须覆盖的真实路径；尚不能认定其中某个是唯一原因。现有真实页面 E2E 已有 SCROLL-SETTLE/CONFIRM/FINISH，可扩展而不新建另一套浏览器框架。顺序遵循 ADR-0015。

## Goals / Non-Goals

**Goals:** 逐片段即时更新；将变化限制在对应条目；以稳定呈现身份维持同一正文节点；几何变化才补偿滚动；临时操作不抢占布局。

**Non-Goals:** 不修改消息权威性、顺序与轮次语义，不猜测缺失的轮次标识；不采用正文节流、延时或 requestAnimationFrame 批量提交；不重新设计所有 Markdown 解析；不把历史渲染工作搬到页面的网络或存储访问中。

## Decisions

### D1 保留即时文字更新，优化更新边界

继续使用当前同步增量接收路径。通过语义稳定的条目模型、稳定回调和条目/正文块组件复用，让未变化的条目跳过重渲染；比较器必须包含正文、状态、交互版本、媒体状态、主题、诊断与回调，不能为提速漏掉可见变化。共享时间格式化器，复用不变的时间显示。Markdown 优先复用已稳定块，仅重新解析/渲染实际变化块，不为命中缓存跨可见条目合并正文。

替代：每帧或定时聚合正文虽能减少提交，但用户明确否决，因此不采用。仅给最外层增加 memo 会被新对象与回调击穿，不能作为完成证据。

### D2 呈现身份与轮次资料解耦

实现前在真实页面可控用例中记录同一 messageId 的节点引用、轮次分组和读取交接时间，锁定触发链。时间线布局以稳定内容身份承载消息节点，轮次分组资料作为可更新属性或不重挂载正文的结构表达，避免同一消息在不同父组间迁移；保持顺序、语义可访问性与原有测试可观测信息。用户输入从 requestId 本地回显接替为正式消息时使用已确认关联，原位接替并在同一状态更新中消除本地回显，不能通过文本相似度推定对应关系。

替代：把缺少 turnId 的内容强行归到邻近轮次会篡改事实，不采用。仅保留子节点 key 无法避免父级重建，不足以解决问题。

排序约束：已取得权威位置的用户消息仍与其他正式条目一同按 Owner 序号排列；禁止为了维持父分组，把有本地提交关联的正式消息强行前置到整轮最前，或把无轮次消息挪到连续轮次之前。例如正式条目序号为思考 10、用户消息 11、回复 12，接替后必须仍是 10/11/12，即使用户消息缺少 turnId。稳定节点应通过稳定条目层级（必要时改为平级条目、将分组资料作为属性）达成，不以改变权威顺序换取。新增回归必须覆盖有/无 turnId 的正式接替插入同轮可见输出之间。

### D3 文字更新与几何处理分离

以真实尺寸变化、用户滚动、宽度变化、显式展开/收起、分页前置和页面恢复触发几何处理；去除每个正文字符无条件遍历所有块的热路径。同次几何处理先集中读取，再一次性写滚动，保留在绘制前完成必要补偿的路径。同行追加实际高度未变则不重新定位。底部跟随无需捕获历史锚点；上读才保存当前第一条可见内容及偏移，锚点被折叠或内容接替时选择确定的存续条目，避免陈旧锚点回拉。

替代：按换行符数推算高度会漏掉软换行、Markdown 表格/代码、图片、字体和宽度变化，不采用。几何观察可以合并重复通知，但不得延后正文呈现，也不得制造一帧旧位置。

### D4 悬浮入口按适用范围稳定切换

快捷收起保留当前有效目标，使用进入/退出不同的小像素容差消除边缘抖动；容差只控制按钮展示，不改变真实跟随底部判据。目标折叠、离开范围、切换会话立即失效。回到底部入口不因程序滚动补偿的短暂几何读数切换。发送/停止切换不自动弹出禁用 tooltip，但键盘/鼠标主动查看仍可取得真实不可用原因，真实失败与授权保留。

### D5 验证逐片段与完整生命周期

浏览器用可控增量驱动真实页面，分别断言单个片段不等后续内容、同行追加 scrollTop 不变、实际换行跟随、上读锚点稳定、收尾同一消息节点连续、已完成条目更新次数不随新回复片段线性增加、悬浮入口微小波动稳定且失效及时。真实 Daemon 复验记录页面脚本时间、长帧、布局次数及收尾节点变更，同设备同内容比较，避免把机器相关采样数字写成跨设备硬门槛。既有普通完成默认折叠仍有效，节点连续性不禁止真实折叠。

## Risks / Trade-offs

- 比较器遗漏实际变化 → 用工具状态、授权版本、媒体就绪、主题和诊断切换回归验证；优先稳定输入引用而非巨型手写比较。
- 改动分组结构影响屏幕阅读器与测试 → 保留轮次资料和顺序断言，更新对应选择器，不删除语义测试以求通过。
- 尺寸观察回调时序导致先绘制后补偿 → 逐帧采样并检查连续消息节点；失败时保留必要同步补偿，不退回每字符全表测量。
- 隐藏页面与零高容器 → 保留既有不覆盖阅读位置的规则，恢复可见重新测量。
- 性能采样包含浏览器及仪器开销 → 控制内容和工具一致，分别记录有监测与轻量复验，不以单次帧率断定唯一瓶颈。

## Migration Plan

仅前端资源变更，无数据库或协议迁移。主检出验证后重新构建 Web 资源，在真实页面确认实际加载的构建版本再复验；不以旧部署的表现验收新代码。回滚只恢复本次前端改动和对应静态资源，不清理用户缓存、密钥或会话数据。
