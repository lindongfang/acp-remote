## Context

现有时间线在进入上读时记录一次锚点，之后继续滚动不更新；临时等待署名和光标在实际内容到达时被替换。顶部 Agent 胶囊使用节点目录，不能代表会话子 Agent。

## Goals / Non-Goals

目标是稳定三段布局、统一滚动写入、支持快捷折叠，并按参考图重排输入。保留真实失败和有效交互信息；不推测子 Agent 生命周期，不扩展未经确认的协议。

## Decisions

1. 对话区持有相对定位容器，悬浮控件绝对定位，不参与高度分配。
2. 禁用浏览器自动滚动锚定，以同步宿主滚动事件持续记录可见条目。绘制前和尺寸观察回调使用同一套补偿；隐藏时不改写位置。
3. 不插入正常等待署名、光标及历史补齐文字行；发送/停止表达执行状态。
4. 思考设置消费 `thought_level` 配置，沿用既有 `session.config.set`，不新造配置值。
5. 子 Agent 真实存活清单缺少协议数据，完整生命周期和摘要展示等待用户确认扩展；当前明确显示缺失，不使用节点目录凑数。

## Risks / Trade-offs

真实浏览器必须验证滚动和尺寸变化；静态渲染测试不能证明布局稳定。后台恢复的内容一致性仍由现有读取和命令状态负责。

## Migration Plan

无需数据迁移。客户端可独立回退组件改动。

## Open Questions

用户是否同意将子 Agent 生命周期与摘要的协议扩展纳入此次范围。
