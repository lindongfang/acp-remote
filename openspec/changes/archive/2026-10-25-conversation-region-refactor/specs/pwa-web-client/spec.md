## ADDED Requirements

### Requirement: 对话区域布局与阅读位置稳定

客户端 MUST 将会话头、对话滚动区域、输入区划分为独立区域，正常等待 MUST NOT 插入临时文本或署名行；滚动位置 MUST 由单一补偿机制维护。

#### Scenario: 底部接收流式正文

- **WHEN** 用户处于底部且正文增长
- **THEN** 页面按实际布局增长同步跟随，不添加滚动动画

#### Scenario: 上读后继续滚动

- **WHEN** 用户离开底部并继续滚到另一处历史内容
- **THEN** 后续流式输出不将页面拉回最初离开底部的位置

#### Scenario: 展开块跨越顶部

- **WHEN** 展开块的表头滚出对话区域顶部且正文仍覆盖顶部
- **THEN** 对话区顶部显示对应块的快捷收起入口，收起后显示该块标题

#### Scenario: 页面恢复可见

- **WHEN** 页面隐藏后恢复可见
- **THEN** 隐藏时不覆盖阅读位置，恢复时保留历史阅读位置或原有底部跟随状态

### Requirement: 输入区工具栏顺序

客户端 MUST 在输入文字下方左侧固定添加入口，右侧依次呈现上下文占比、模式、模型、思考模式及发送或停止按钮。未上报的用量或配置 MUST NOT 被伪造。

#### Scenario: 执行中取消

- **WHEN** 当前轮次可取消或正在等待取消确认
- **THEN** 发送位置显示停止按钮，确认期间禁止重复取消

#### Scenario: 子 Agent 信息缺失

- **WHEN** 协议未提供当前会话子 Agent 生命周期
- **THEN** 页面明确显示信息缺失，不将节点目录表示为本会话子 Agent
