# Spec Delta

## ADDED Requirements

### Requirement: 改动差异行按行级差异派生且有界

系统 SHALL 在派生文件改动事件时，从同一次类型化 Diff 的旧文本与新文本按行级差异派生结构化差异行，每行 SHALL 标明它是新增、删除还是上下文。派生 SHALL 受固定的行数与字节上限约束；超限时系统 MUST 改为只下发统计并把该次派生标记为差异行未下发并给出已登记原因，MUST NOT 下发被截断或被裁剪的差异行，也 MUST NOT 让消费方把省略理解成该处改动没有内容。差异内容 MUST NOT 被文本化进统计或摘要字段。

#### Scenario: 派生新增与删除行

- **WHEN** 一次含类型化 Diff 的工具调用被派生为文件改动事件，且差异规模在上限内
- **THEN** 该事件带结构化差异行，逐行标明新增、删除或上下文

#### Scenario: 超限时显式省略

- **WHEN** 一处改动的差异超过固定的行数或字节上限
- **THEN** 该事件只带统计并标记差异行未下发、给出已登记原因，MUST NOT 带被截断的行

#### Scenario: 派生不改写 ACP 原文

- **WHEN** 一处改动被派生为带差异行的事件
- **THEN** 该事件携带的 ACP 原文字节、其摘要与字节长度与派生前完全相同

#### Scenario: 差异无法判定时不编造

- **WHEN** 旧文本缺失或两侧文本无法形成行级对应
- **THEN** 该次派生按既有口径省略差异行与统计，MUST NOT 用零值或整段替换冒充判定结果
