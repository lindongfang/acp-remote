## Purpose

定义 core 派生并持久化的结构化事件与单向字段更新：文件改动的行数统计与相对化展示路径、Agent profile 进程的节点级连接生命周期，以及由 Agent 通知驱动的会话标题更新；这些事件的共同点是协议早已登记却长期没有生产者。

## ADDED Requirements

### Requirement: 文件改动事件由类型化 Diff 派生

系统 SHALL 在收到含文件改动的工具调用时派生文件改动事件，并把该事件的来源限定为 ACP 工具调用内容中的类型化 Diff 元素。系统 MUST NOT 为不含文件改动的工具调用派生该事件，也 MUST NOT 为同一处改动重复派生。派生 MUST NOT 改动该次 ACP 原文的字节、其摘要与字节长度，未能派生的原文仍按既有口径完整保留。

#### Scenario: 含 Diff 的工具调用产生一个改动事件

- **WHEN** Agent 的一次工具调用内容中包含一个文件 Diff 元素，指向会话工作目录内的某个文件
- **THEN** 该会话持久化并广播恰好一个文件改动事件，其展示路径为该文件相对会话工作目录根的路径

#### Scenario: 不含文件改动的工具调用不产生事件

- **WHEN** Agent 的一次工具调用内容中只有普通内容块与终端引用，没有任何 Diff 元素
- **THEN** 该次工具调用不产生文件改动事件，其它类型的结构化事件不受影响

#### Scenario: 派生不改写 ACP 原文

- **WHEN** 一个含 Diff 的工具调用被派生为文件改动事件
- **THEN** 该事件携带的 ACP 原文字节、其摘要与字节长度与派生前完全相同

### Requirement: 改动行数按行级差异统计

文件改动事件的视图 SHALL 携带新增行数与删除行数两项可选统计。行数 MUST 由改动前内容与改动后内容之间的行级差异得出：新建文件的全部行计为新增且删除为零；删除文件的全部行计为删除且新增为零。系统 MUST NOT 用改动前后两段文本的行数相减来代替行级差异统计——当两段文本行数相等但内容不同时，该口径 MUST 仍报告出非零的改动行数。无法从工具调用中判定改动行数时，事件 SHALL 省略这两项，MUST NOT 以零代替未知。

#### Scenario: 行数相等但内容不同时仍报告改动

- **WHEN** 某次文件改动的改动前内容与改动后内容行数相同，但其中若干行被替换为不同内容
- **THEN** 事件的行数统计报告出非零的新增与删除行数，MUST NOT 报告为零改动

#### Scenario: 新建文件全部计为新增

- **WHEN** 某次文件改动的改动前内容不存在而改动后内容存在
- **THEN** 新增行数等于改动后内容的行数且删除行数为零

#### Scenario: 判定不出时省略而非填零

- **WHEN** 某次工具调用的 Diff 元素缺少可用于计算行数的改动后内容
- **THEN** 事件省略行数统计两项，客户端据此呈现为「未同步」或不可用，MUST NOT 呈现为「零改动」

### Requirement: 展示路径相对化且不泄漏工作区外结构

文件改动事件的展示路径 MUST 由工具调用给出的路径相对化到该会话的工作目录根得出，MUST NOT 直接下发工具调用给出的绝对路径。当该路径不在会话工作目录根之下时，系统 SHALL 把事件标记为位于工作区之外，并且展示路径 MUST NOT 包含回退层级或工作目录根的任何片段。位于工作区之外的判定 MUST 基于规范化后的前缀关系，MUST NOT 仅按字符串前缀判断。

#### Scenario: 工作区内的路径相对化下发

- **WHEN** 某次文件改动的路径位于该会话工作目录根之下
- **THEN** 事件的展示路径是该路径相对工作目录根的形式，不含工作目录根的任何片段，也不含回退层级

#### Scenario: 工作区外的路径被显式标记

- **WHEN** 某次文件改动的路径经规范化后不在该会话工作目录根之下
- **THEN** 事件被标记为位于工作区之外，展示路径只给出该文件的名称，MUST NOT 包含回退层级或工作目录根的片段

#### Scenario: 同名前缀不被误判为工作区内

- **WHEN** 该会话工作目录根为某路径，而某次改动的路径以该路径的字符串作为前缀但并不位于其之下
- **THEN** 该次改动被判定为位于工作区之外，MUST NOT 因字符串前缀相同而被当作工作区内

### Requirement: Agent 连接状态是节点级生命周期

Agent 连接与断开事件 SHALL 是节点级事件：其会话标识 MUST 为空，且其生命周期归属于 Agent profile 的进程而非任何单个会话。同一 profile 的进程可被多个会话复用，因此该事件 MUST NOT 表达某个会话的活跃程度。事件的状态取值 SHALL 是封闭词表，连接事件的取值与断开事件的取值各自唯一且互不相同。系统 MUST NOT 用这些事件表达会话的运行中或空闲状态。

本能力覆盖事件的**产生与持久化**。这些事件当前没有投递通道：唯一已实现的入站适配器按会话归属投递，MUST NOT 因此要求本次变更改变该投递规则。因此客户端能否呈现覆盖层，SHALL 取决于后续同步入站面的落地；在该通道就绪前，客户端 MUST 把缺失的覆盖层呈现为状态未知，MUST NOT 以其它信号推断连接状态。

#### Scenario: 进程建立时产生一次连接事件

- **WHEN** 某个 Agent profile 的进程首次建立并可服务会话
- **THEN** 该节点持久化一次会话标识为空的连接事件，且此后该进程被多个会话复用时不再重复产生该事件

#### Scenario: 进程退出时产生一次断开事件

- **WHEN** 某个 Agent profile 的进程退出，包括被空闲回收终止的情况
- **THEN** 该节点持久化一次会话标识为空的断开事件，且该事件可携带本次退出的错误信息

#### Scenario: 节点级事件不被会话级投递路径误收

- **WHEN** 一个会话标识为空的事件经过按会话归属投递的入站路径
- **THEN** 该路径不投递该事件，MUST NOT 把它归属到任意会话，MUST NOT 为其伪造会话级游标

#### Scenario: 状态取值来自封闭词表

- **WHEN** 客户端收到一个 Agent 连接或断开事件
- **THEN** 其状态字段的取值是该事件类型对应的唯一取值，客户端可据此区分两种事件，MUST NOT 依赖其它取值或自由文本来判断

#### Scenario: 不表达会话活跃程度

- **WHEN** 一个会话处于运行中而其所用 profile 的进程早已建立
- **THEN** 该会话的运行中状态只体现在会话摘要的状态字段，Agent 连接事件不因会话活跃而重复产生

### Requirement: 会话标题只由 Agent 通知更新

系统 SHALL 在收到 Agent 的会话信息更新通知时，把其中携带的标题写入该会话的标题取值，并据此更新会话摘要与会话信息变更事件。该更新 MUST 是单向的：客户端 MUST NOT 构造会话信息变更事件，系统 MUST NOT 提供任何由客户端发起的重命名会话的入口。当通知只携带更新时间而不含标题时，系统 MUST 保持既有标题不变；当通知显式把标题置空时，系统 SHALL 把该会话的标题更新为空值，并据此向客户端呈现为未命名会话。会话创建时标题为空，既有会话在被通知更新前 MUST 保持为空。

#### Scenario: 首次通知写入标题

- **WHEN** 一个创建时标题为空的会话收到携带非空标题的会话信息更新通知
- **THEN** 该会话的标题变为通知中的取值，会话摘要随之反映该标题

#### Scenario: 只有更新时间时保持标题不变

- **WHEN** 一个已有标题的会话收到只携带更新时间、不含标题的会话信息更新通知
- **THEN** 该会话的标题保持不变，更新时间被更新

#### Scenario: 通知清空标题时呈现为未命名

- **WHEN** 一个已有标题的会话收到把标题显式置空的会话信息更新通知
- **THEN** 该会话的标题变为空值，客户端据此呈现为未命名会话

#### Scenario: 客户端无重命名入口

- **WHEN** 客户端希望修改某个会话的标题
- **THEN** 命令目录中不存在任何用于修改会话标题的命令，系统亦不提供绕过 Agent 通知直接写入标题的路径

#### Scenario: 标题未生成时保持未命名

- **WHEN** 一个已创建但尚未收到任何会话信息更新通知的会话
- **THEN** 其标题为空，客户端呈现为未命名会话，系统 MUST NOT 以其它字段拼装出一个替代标题
