# Platform Keystore 增量

## MODIFIED Requirements

### Requirement: 密钥与凭据不进入可观察的非安全位置

系统 SHALL 让私钥材料、封装后的密钥字节与 Provider 凭据值只经安全存储边界进出。这些值 MUST NOT 出现在日志、错误消息、`Debug`/序列化输出、测试快照、协议载荷或普通数据库字段中；可以落库的只有不透明条目标识、字段名与版本号。本变更后密钥库只承载节点/设备身份密钥：Provider 凭据值与 Provider 引用不再由本系统持有或存储。

#### Scenario: 调试输出不含密钥材料

- **WHEN** 对包含秘密的类型做格式化或调试输出
- **THEN** 输出中不出现私钥字节、封装字节或凭据值

#### Scenario: 记录与错误不携带秘密

- **WHEN** 一次签名或密钥读取失败并产生日志与错误
- **THEN** 日志与错误只包含条目标识、用途与错误分类，不含秘密内容或堆栈中的明文

#### Scenario: 普通数据库只保存引用

- **WHEN** 检查保存节点/设备身份引用的普通数据库行
- **THEN** 该行只有条目标识与不透明元数据，没有私钥材料；数据库中不存在 Provider 引用或凭据值
