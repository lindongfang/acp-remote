## Context

访谈见 docs/file-list-refresh-interview.md；所有行为已获用户确认。协议每页128项和正文读取不变。

## Goals / Non-Goals

目标是可预测的文件列表刷新与明确反馈；不增加定时轮询、目录监听、正文自动替换。

## Decisions

- Store 跟踪当前会话、已展开目录和刷新轮次；同轮全部请求结束后归约成功/失败。
- 组件上报可见已展开目录；组合根通过已有 LifecyclePort 传递前台恢复。
- file.changed 只标记正文过期，列表刷新取消；分页请求与整轮刷新结果分离。
- 暂时失败保留旧列表，重连丢弃旧连接请求后重新读取；同来源在途触发合并。
- 按钮动画和短暂完成反馈有组件所有者与卸载取消路径，遵守减少动态效果偏好。

## Risks / Trade-offs

展开多个目录会增加请求数量；遵守现有协议限额并合并重复触发。旧分页续页不得混入刷新后的第一页。

## Migration Plan

不变更存储和wire；发布客户端静态资源即可，回滚客户端即可恢复旧交互。
