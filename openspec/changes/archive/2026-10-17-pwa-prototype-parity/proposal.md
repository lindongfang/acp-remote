## Why

原型 `prototypes/acp-remote-pwa.html` 在提交 `29fd6d7`（2026-10-16）做了一轮迭代：目录浏览建会话、详情页改一页列表、顶栏状态归一。**这轮迭代的结论没有同步进 `clients/app`**，于是原型与实现之间同时积压了两类差距：

1. **结构性差距（这次迭代直接造成的）。** 详情页现在还有月份分档、目录内搜索与「当前显示 N / M」，原型已经改成「按时间倒序 + 每页 10 条 + 页码翻页」；目录项还在显示别名与「最近活动时间」，原型已经删掉这两样、改成同名时显示路径尾段；目录页工具条右侧缺原型已经画出的「⊕ 新建（指定目录建会话）」入口；新建弹层缺「选择文件夹」这条链路。
2. **视觉与外壳差距（一直没做）。** 实现里**没有共享外壳**：目录页、详情页、对话页各拼一条互不一致的窄导航，`hosts`/`pair`/`session` 三个路由的外层还是裸 `<main><nav>`；原型那套顶栏（设备胶囊、开发模式徽标、主题开关、帮助按钮）在实现里完全不存在。`ContextUsageBar`、`DiagnosticsDrawer`、`DegradedEventCard`、`PairingPanel` 四个组件至今**不带任何样式**（裸 `div/span/progress/dl/pre`）。对话页是两栏，原型是三栏（左栏同目录会话列表）；输入区没有 Enter 发送、没有上下文胶囊与模型/模式弹层；代码复制与链接点选**组件给了按钮但页面没有接线**，点了没反应。

为什么现在做：这两个变更一起把「原型即实现」这条口径重新对上——原型是 `FRONTEND_DESIGN.md` §9 第 1 条登记的交互口径来源，继续让它与实现分叉，会让后续每次前端改动都要先做一次考古。

**用户原始要求**：原型 `acp-remote-pwa.html` 的目录页、详情页、对话页样式都有调整，前端页面参照原型同步更新；要完整对齐原型，前后端都要对齐；先探索有哪些修改，再新建 change。

**硬约束**：

- 前端 SHALL NOT 反向迫使核心引入平台特例；平台差异仍收敛在 `src/platform/**`。
- CSP 基线不变：`default-src 'self'; script-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'`。样式仍需由同源外部样式表交付（`/rnw-stylesheet.css` 必须保持为空，入口文档的 reset 走 `/entry-reset.css`）。
- 设备身份与配对链路、连接状态机、命令终态语义、事件去重、imported 的 no-content-cache 边界**不改**——本次只改呈现层与三页的信息结构。
- 不新增第三方依赖；不引入样式库或 web-only CSS 文件。
- 路径展示与结构化 diff、节点目录浏览所依赖的协议能力由变更 `sync-path-browse-and-diff-delivery` 提供；本变更 MUST NOT 绕过 wire 自行构造或推导这些值。

**非目标**：

- 不实现 Android/iOS 原生包、不实现 PWA 安装（manifest/service worker）、不做 i18n。
- 不实现 Node Link 面的结构化历史（`NODE_LINK_PROTOCOL.md` §12.7 的既有缺口）。
- 配对页的 18 个状态与 `hosts` 页的完整信息集合不属本次范围，本次只把它们纳入共享外壳（顶栏、抽屉、样式基座）。
- 原型自带的「原型控制台」不属产品 UI，不移植。

**成功判据**：

- 目录页、目录详情页、对话页在浏览器里的呈现与原型逐项对齐（结构、分区、控件、文案口径、列宽、状态色），差异清单只剩下面登记的那些。
- 顶栏、开发模式横幅、主题开关（跟随系统/白天/黑夜）、帮助抽屉、toast 在全部路由可用且行为一致。
- `clients/app` 的 `npm run check`（typecheck + vitest + `expo export`）与 `node e2e/run-e2e.mjs` 全绿，且新增/改写后的浏览器用例能在原型被改回去时变红。
- `npm run check`（根合同门禁）全绿。

### 与原型的四处**有意偏离**（不是遗漏；理由见下表，前三处另有 `design.md` 的对应决策）

| 偏离 | 原型 | 本变更 | 理由 |
|---|---|---|---|
| 响应式断点 | 三页没有任何宽度断点（全文件唯一 `@media` 是 `prefers-reduced-motion`） | 保留现有 720px 断点：宽屏用原型的多栏形态，窄屏收成单列 + 次级视图切换 | `FRONTEND_DESIGN.md` §4.1 与 §9 把响应式手机布局列为必须实现与验收项；删掉断点会让手机不可用 |
| 来源与同步时刻标注 | 目录页与详情页没有该标注（对话页中栏有连接状态条；详情页那条离线提示的开关无人置位，实际不可达） | 保留「内容来自上次同步 + 同步时刻」，改成原型的条状（`connstrip`/`notice`）语言放在页面顶部 | 这是本地优先产品在断连时的关键信号（`pwa-web-client` 既有需求），原型没画不等于要删；原型的连接状态条本身就是同一语义的另一种位置 |
| Agent 连接状态 | 胶囊里把覆盖层缺席写成「已断开」 | 缺席仍呈现为「状态未知」 | `pwa-web-client` 既有需求明确禁止把缺席当作已断开；原型那三行是硬编码 mock |
| 授权按钮的文字色 | 三个实心应答按钮的文字写死 `#fff`，深色主题下仍是死白 | 用「表面色」token：浅色主题下等价于白色，深色主题下改用该主题的表面色 | 仓库约定颜色只经 `theme.ts` 的 token、不写死 hex；深色主题下死白压在 `--accent:#8098f9` 上对比度约 2.2:1，不可读 |

## What Changes

**一、共享外壳（新增）**

- 新增全局顶栏：logo（`ACP Remote` + 方块标记）、设备胶囊（圆点颜色 + 异常短词 + 内联 SVG 折角，点击开主机面板）、开发模式徽标、主题开关、帮助按钮。连接状态**只**由这一个胶囊表达，不再散落其它徽标。
- 新增开发模式横幅（明文连接时显示）、帮助抽屉 + 遮罩、全局 toast。
- 新增主题三态（跟随系统 / 白天 / 黑夜）与持久化偏好；系统偏好变化时跟随。
- 全局滚动条样式与 `prefers-reduced-motion` 处理。
- `hosts` / `pair` / `session` 三个路由的外层由裸标记改为共享外壳；配对页按原型隐藏全局顶栏并呈现自己的头部。

**二、目录页**

- 卡片头改为原型的八个槽位：折叠箭头（SVG，折叠时旋转）、目录图标、展示名、（同名时）路径尾段、`N 个` 计数胶囊、运行中/待处理徽标（数量为 0 时不呈现）、弹性空白、`⊕ 新建`、`查看全部 ›`。
- 卡体改为缩进树（左缩进 + 2px 竖线）；会话行改为原型的五字段：状态圆点（运行中带呼吸动画）、标题（空标题斜体「未命名会话」）、状态词（待授权 / 等你回复）、Agent、时间。
- 时间口径改为相对：1 分钟内「刚刚」、1 小时内「N 分钟前」、否则年月日（UTC）。
- **界面不再出现别名**；同名目录以路径尾段消歧（路径来自变更 `sync-path-browse-and-diff-delivery`）。
- 移除目录项上的「最近活动时间」（原型这一轮明确删掉了它）。
- 「查看全部」文案改为不带 N 的「查看全部 ›」；0 会话目录仍可进入详情页（保留实现优于原型之处）。

**三、目录详情页**

- 页头改为：返回「‹ 目录」、标题 + `N 个会话` 计数胶囊、路径两行（淡标签 + 等宽值）。
- 正文改为平铺按时间倒序、每页 10 条；**移除**月份分档、月份切换、目录内搜索与「当前显示 N / M」。
- 底栏改为一行：左侧 `⊕ 新建` + 副作用提示，右侧分页（上一页 / 页码输入框 / 下一页；只有一页时不呈现）。

**四、对话页**

- 宽屏改为原型的三栏网格（300 / 1fr / 360）：左栏为目录上下文（目录名 + 完整路径 + 「全部 ›」+ 目录内搜索框）+ 同目录会话列表（状态圆点 + 标题 + 时间）+ 「已显示 N / M + 加载更多」+ 吸底「⊕ 新建会话」；中栏为会话头 + 连接状态条 + 对话流 + 输入区 + 跳转胶囊；右栏为变更文件列表 + 结构化 diff。
- 中栏头部：标题、状态徽标、Agent 名、Agent 胶囊（悬停/聚焦展开本会话涉及的 Agent 列表，缺覆盖层时呈现「状态未知」）。
- 输入区改为原型的组合：上下文胶囊（进度条 + 占比 + 已用/上限，未上报时显示「—」）+ ≥85% 时的警告条 + 模型/模式选择胶囊与弹层 + 输入行（三态占位符与发送/停止按钮）+ 提示行（Enter 发送 · Shift+Enter 换行 · 附件不受支持）。
- 新增 Enter 发送 / Shift+Enter 换行；新增「跳到你最近的输入」胶囊与待处理交互跳转条。
- 流内条目改为原型的形态：用户消息靠右气泡、Agent 气泡走 Markdown、代码卡带语言条与复制入口、结构化折叠块（思考/工具/终端/计划，可展开收起并与右栏联动）、权限卡三按钮、降级卡、运行中指示、失败条。
- 接线既有但未接的回调：代码复制、链接点选。
- 右栏渲染变更文件列表与**结构化 diff 行**（由变更 `sync-path-browse-and-diff-delivery` 下发；没有结构化来源时仍呈现明确说明，不编造）。
- 四个裸标记组件（`ContextUsageBar`、`DiagnosticsDrawer`、`DegradedEventCard`、`PairingPanel`）迁到样式基座。

**五、新建会话与选择文件夹**

- 新建弹层补「选择文件夹」控件：已知目录进来时呈现「目录 / 路径」两行；顶部入口进来时呈现「选择文件夹」按钮 + 已选路径 + 说明，并给出四类分支提示（形状非法 / 目录不可建 / 目录待新建 / 目录已存在）。
- 新增「选择文件夹」弹层：面包屑（首段「此电脑」）+ 上一级 + 逐层目录列表（已登记目录标注）+ 新建文件夹 + 页脚（当前路径 / 取消 / 选择此文件夹，此电脑层禁用确认）。

**六、规格与文档**

- `openspec/specs/pwa-web-client/spec.md` 的一批需求按上述口径改写、新增与移除。
- `docs/FRONTEND_DESIGN.md` §4.1 与 §9 写回新的呈现口径（三栏、分页、外壳、主题、相对时间、路径展示的前置条件）。

## Capabilities

### New Capabilities

无。本变更只改既有 `pwa-web-client` 能力的可观察行为。

### Modified Capabilities

- `pwa-web-client`: 目录页的信息集合与时间口径、目录详情页的组织方式（月份分档 → 分页）、对话页的形态（两栏 → 三栏）与输入区行为、共享外壳与主题、复制与链接的可用性、路径与结构化 diff 的呈现边界——这些需求的行为契约都要改写；同时移除「目录内搜索」「按月分档」「目录项最近活动时间」三条既有需求。

## Impact

- **前端代码**：`clients/app` 的 `app/**`（三个路由组件与根布局）与 `src/components/**`（约 22 个已样式化组件 + 4 个裸标记组件）；`src/features/**` 的目录与对话页视图模型（分页、相对时间、左栏会话列表、外壳状态）；`src/components/theme.ts` 的 token 与尺度（补断点、字重、层级、动效）。
- **客户侧依赖**：需要变更 `sync-path-browse-and-diff-delivery` 交付的路径字段、目录浏览命令与结构化 diff 行；在这些合同落地前，本变更的实现工作包可以并行开工，但涉及路径/浏览/diff 的三处呈现只能在该变更合入后验收。
- **测试**：`clients/app/src/**/*.test.ts` 中锁住旧信息结构的断言要改写（重点是 `r15-directory-detail.test.ts`、`r15-directory-list.test.ts`、`directory-filter.test.ts`、`conversation-page.test.ts`、`conversation-responsive.test.ts`、`file-changes-panel.test.ts`、`theme.test.ts`）；`clients/app/e2e/page/checks/**` 中 `r15-directory*.ts`、`conversation-*.ts`、`ui-stylesheet.ts` 的锚点要随结构更新。
- **文档**：`docs/FRONTEND_DESIGN.md` §4.1/§9；`AGENTS.md` 与其它权威文档不改。
- **不受影响**：协议 wire、`schemas/`、`fixtures/`、`compatibility/`、任何 Rust crate（由变更 `sync-path-browse-and-diff-delivery` 承担）。
