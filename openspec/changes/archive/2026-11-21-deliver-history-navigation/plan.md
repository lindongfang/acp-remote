# 历史导航实施计划

## Execution Model

主执行者按 openspec/role/ 分配角色。独立 reviewer 合审规格、设计及独立 tester 的用例后，coder 实现并自测。集成后由独立 tester 和 reviewer 对同一提交验收和检视。

## Parallel Assessment

轮次模型与协议字段冻结后，快照存储和 Web 分别在独立工作区开发。节点集成需要快照接口，浏览器联调需要节点命令，两者串行。
