## Purpose

定义由用户显式选择外部原生会话并接入平台的行为边界，保持原生身份在其范围内唯一绑定，区分导入历史和后续新输出，同时如实说明外部占用、历史缺失与不支持能力，不建立隐式扫描或持续同步承诺。

## ADDED Requirements

### Requirement: 显式选择与能力门禁
系统 SHALL 仅在用户显式请求时按Harness实际能力列出或接管原生会话；未支持的列表、历史或接管能力 MUST 明确报错，不自动扫描和持续同步外部历史。

#### Scenario: 无原生列表能力
- **WHEN** 适配器不支持列出外部会话
- **THEN** 系统明确说明限制，仅在存在已验证按标识接管路径时允许该路径

### Requirement: 范围内唯一绑定
系统 SHALL 在Harness原生范围内原子校验原生会话唯一绑定，重复或并发绑定 MUST 拒绝并返回已有绑定信息的授权视图，不创建第二个平台会话。

#### Scenario: 并发接管同一原生会话
- **WHEN** 两客户端同时接管同一原生范围及原生ID
- **THEN** 至多建立一个绑定，另一请求明确冲突

### Requirement: 导入与实时输出隔离
系统 SHALL 将可靠身份的导入历史与新输出分别关联来源，保持各自真实顺序；不能按内容相同去重，缺失、未提供或无法可靠关联的历史 MUST 明确标记，不宣称完整导入。

#### Scenario: 原生历史不可读取
- **WHEN** 接管可恢复上下文但无法读取旧历史
- **THEN** 明确显示旧历史缺失，后续新输出正常保存，不补造旧消息

### Requirement: 外部占用与接管失败
系统 SHALL 在有可靠占用检测时拒绝或呈现占用，无检测能力时明确限制；接管失败 MUST 不显示已接管，不承诺外部CLI与平台并发写入一致性。

#### Scenario: 检测到外部写入占用
- **WHEN** 原生会话被可靠检测为外部占用
- **THEN** 接管被拒绝并提示释放外部占用，不强制改写原生状态
