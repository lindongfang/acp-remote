# 交付外部原生会话显式接管

状态：待实现文档齐备；独立方案结论见 review.md，产品未实施；上游真实交付和能力探测门禁仍需满足。

## Why

当前分支没有产品实现。为按重设计建立可独立验收的交付闭环，需要交付外部原生会话显式接管，避免仅交付孤立模块而没有可观察结果。

### 硬约束与非目标

- 以[重设计 §2.2、§4.3–§4.4、§6.3、§7.3](../../../docs/HARNESS_CONTROL_PLANE_REDESIGN.md)为本闭环依据；采用新架构、不兼容旧系统，其他适用的全局约束仍然有效。
- 外部 CLI 与平台同时写同一原生会话的一致性不在承诺范围。
- 本轮补齐待实现文档，不开始产品实现，不将规划或模拟结果写成已提供能力。首期限定 Windows 节点 + Web，App 后续。

### 本 change 的成功判据（待详细规格转成场景）

- SC1：按 Harness 实际能力选择并显式接管外部会话，校验原生范围内唯一绑定，隔离导入历史与新输出。
- SC2：固定版本逐款验证可用路径；重复绑定被拒绝，外部占用及缺失历史明确呈现；不靠内容相同去重，不自动扫描持续同步外部历史。
- SC3：建立真实构建及适用检查，完成独立用例/方案检视和交付验收；记录未验证项及实质限制。
