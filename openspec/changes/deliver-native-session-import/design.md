## Decisions

### 1. 职责与权威

基础发现与浏览前移至首个闭环；本目录 ID 保留，不意味着继续导入聊天。接管将已有原生会话纳入平台执行所有权，不复制内容。

### 2. 来源能力与接口

启动配置和连接身份不进入原生目标的区分键；配置显式引用同一接入来源时，同来源同原生ID经多安装或别名访问复用执行归属及加载名额。不同来源分别管理，不自动判断其物理存储是否相同，也不承诺跨来源互斥。该通用身份与所有权端口由首个闭环提供，完整子树浏览不作为基础接管前置。

按显式接入来源及原生会话标识判定同来源跨入口身份，其唯一约束用于协调平台执行绑定与加载，不用于建立独立历史容器；普通浏览不要求执行绑定。不要求 ACP 提供物理存储等价性证明，不新增厂商探测或私有目录解析。需要实际加载时统一走原生恢复及容量接口。

子目标接管复用 session-resource-policy 的主树归属规则；先确认可靠主树所有者并申请或复用树名额，再调用加载，不独立管理子会话。根尚未打开不免除计数；根已删除或归属不可验证时拒绝实际加载，保留可用的无加载查询。接管后续失败仍由原所有者清理，确认该树无所属资源前不归还名额。

### 3. 状态与失败

重新接管先满足通用标准重放准入，再校验来源并协调重放，隔离旧内容与新输出。不再使用导入批次、永久正文暂存及原子发布完整聊天档案；无重放时拒绝接管，不提供当前连接降级。重放期间的有界候选视图不等于永久导入，不为此开发厂商读取器。

### 4. 资源与安全

可靠外部占用检测时拒绝不安全加载；无检测时说明限制，不承诺外部并发写一致。加载后失败保留资源所有权并清理，未知副作用不重发。
