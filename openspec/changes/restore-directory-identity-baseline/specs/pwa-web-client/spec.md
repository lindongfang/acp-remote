# PWA Web Client 增量

## MODIFIED Requirements

### Requirement: 目录页提供搜索与状态筛选

目录页 SHALL 提供按目录匹配的搜索与按会话状态匹配的筛选，二者可叠加。搜索 SHALL 匹配由服务端下发的路径派生的目录展示名，以及该目录下会话的标题，且大小写不敏感。目录标识 MUST NOT 参与搜索，MUST NOT 作为搜索结果或界面文本呈现。筛选 SHALL 提供「全部」「运行中」「待处理」三个取值，分别表示不过滤、存在排队中或运行中的会话、存在等待输入或等待授权的会话。这些判定 MUST 只使用已同步的快照资源，MUST NOT 依赖任何在线查询命令。

#### Scenario: 按目录名或会话标题搜索

- **WHEN** 用户在目录页输入一个查询词
- **THEN** 列表只保留展示名或名下会话标题命中该词的目录，其余目录不呈现

#### Scenario: 目录标识不参与搜索

- **WHEN** 用户输入一个只命中某个目录标识的字符串
- **THEN** 该目录不因标识命中而保留在结果里；目录标识也 MUST NOT 出现在结果文本中

#### Scenario: 按会话状态筛选

- **WHEN** 用户选择「运行中」或「待处理」
- **THEN** 只呈现至少有一个相应状态会话的目录，且每个目录仍呈现它自己的会话总数、运行中数与待处理数（汇总不因筛选而改变）

#### Scenario: 搜索无结果

- **WHEN** 搜索或筛选之后没有任何目录命中
- **THEN** 客户端呈现「没有匹配的结果」，与「本机没有任何目录」「目录存在但没有会话」两种空态在三处文案上互不相同

#### Scenario: 搜索与筛选不依赖在线查询

- **WHEN** 用户输入查询词或切换筛选
- **THEN** 客户端不派发任何命令，且断连状态下的匹配结果与在线时一致
