# Spec Delta

## ADDED Requirements

### Requirement: 用配对载荷公钥验证主机证明

配对认领的响应携带主机证明；客户端 SHALL 用配对载荷里固定的主机公钥验证该证明，MUST NOT 使用响应自身携带的公钥或跳过校验。验证失败时 MUST 明确失败、停止后续轮询，且 MUST NOT 写入任何已配对主机记录。

#### Scenario: 验证通过才继续配对

- **WHEN** 认领响应携带的主机证明能被配对载荷里的主机公钥验证通过
- **THEN** 客户端继续轮询配对状态

#### Scenario: 验证失败即停止

- **WHEN** 认领响应的主机证明验证失败（签名不匹配或公钥与载荷不符）
- **THEN** 客户端明确失败、停止轮询，且不写入任何已配对主机记录

### Requirement: 已批准响应的主机公钥必须与配对载荷一致

配对状态查询的响应没有主机签名，因此客户端 SHALL 在状态为已批准时校验响应携带的主机公钥与配对载荷里的那把**逐字节相同**，并校验主机标识一致。任一项不符时 MUST 明确失败，MUST NOT 落盘该主机记录，也 MUST NOT 以跳过校验的方式继续。

#### Scenario: 公钥不一致时拒绝落盘

- **WHEN** 已批准响应携带的主机公钥与配对载荷里的不同
- **THEN** 客户端明确失败，不写入已配对主机记录

#### Scenario: 一致时落盘并触发连接

- **WHEN** 已批准响应的主机公钥与标识都与配对载荷一致
- **THEN** 客户端写入已配对主机记录并进入已配对、触发连接

### Requirement: 会话创建入口与载荷

客户端 SHALL 在已登记目录内提供创建会话的入口，提交载荷 MUST 只包含 Agent 标识与目录引用两类字段（已登记别名，或用户提供的目录）；MUST NOT 包含凭据、MCP 配置或其它字段。设备不再有创建权限这一维度，入口 MUST NOT 再以权限为由不可用，也 MUST NOT 再出现「需要由电脑端授予」的说明。提交期间客户端 MUST 显示创建中状态；收到终态后 MUST 进入新会话或呈现可区分的结构化失败原因；结果不确定 MUST 被显眼呈现且 MUST NOT 被自动消解。

#### Scenario: 提交载荷只含目录引用与 Agent 标识

- **WHEN** 用户在一个目录内选择某个已配置的 Agent 并提交创建
- **THEN** 发出的命令载荷只包含目录引用与该 Agent 标识，不含任何其它字段

#### Scenario: 入口不因权限不可用

- **WHEN** 一台已认证设备打开目录页或目录详情页
- **THEN** 创建入口可用，页面不呈现任何「没有创建会话的权限」类说明

#### Scenario: 创建中与终态分别呈现

- **WHEN** 一次创建会话的命令已发出但尚未收到终态
- **THEN** 界面呈现创建中且不接受重复提交；收到终态后进入新会话，或呈现可区分的失败原因

#### Scenario: 结果不确定显眼且不被自动消解

- **WHEN** 一次创建的结果为不确定
- **THEN** 该状态显眼保留直到用户处理，MUST NOT 被自动判定为成功或失败

### Requirement: 创建入口的副作用说明

目录内的创建入口 SHALL 说明提交会在电脑上启动一个新的 Agent 进程。

#### Scenario: 副作用提示

- **WHEN** 用户在某目录详情页看到创建会话入口
- **THEN** 入口旁呈现「将在你的电脑上启动一个 Agent 进程」的说明

### Requirement: 目录项的创建入口

目录页的每个目录项 SHALL 提供在该目录内创建会话的入口，它与目录详情页的创建入口 SHALL 使用同一条命令，提交的载荷 MUST 只包含目录引用与 Agent 标识。入口 MUST NOT 因权限原因不可用，也不再需要任何权限说明。

#### Scenario: 从目录项直接创建

- **WHEN** 用户从某个目录项触发创建并选定一个已配置的 Agent
- **THEN** 客户端发出的载荷只含该目录引用与该 Agent 标识，不含任何凭据或 MCP 配置

#### Scenario: 创建中与终态的呈现沿用既有约定

- **WHEN** 从目录项发起的创建已提交但未收到终态
- **THEN** 呈现创建中且不接受重复提交；收到终态后进入新会话或呈现可区分的失败原因；结果不确定时显眼保留直到用户处理

## REMOVED Requirements

### Requirement: 会话创建是受限入口

**Reason**：设备不再有创建会话的权限维度，原文的权限门控与「只允许目录别名」的载荷约束都不再成立。

**Migration**：见本 delta 的新增要求「会话创建入口与载荷」。

### Requirement: 创建入口的副作用与权限说明

**Reason**：设备不再有权限维度，「需要由电脑端授予」的说明不再存在；副作用说明本身继续有效。

**Migration**：见本 delta 的新增要求「创建入口的副作用说明」。

### Requirement: 目录项提供目录内创建入口

**Reason**：该要求把目录项入口与「同一份权限判定」绑定，权限判定消失后原文不再成立；入口本身与载荷约束继续有效。

**Migration**：见本 delta 的新增要求「目录项的创建入口」。
