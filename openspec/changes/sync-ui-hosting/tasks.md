# Tasks

## 1. 静态端点与路由（WP1）

- [ ] 1.1 在 `crates/server/src/transport/net/` 的路由表新增第三类「静态 GET」端点，注册在根路径；解析顺序固定为「已注册协议端点 → 嵌入资源命中 → 入口文档回退 → 其余 404」。完成判据：单元测试断言协议端点（Sync/Node Link 的 ws 与两条 pairing POST）不被回退接管。
- [ ] 1.2 实现入口文档与单页回退：根路径返回入口；非协议路径在资源表未命中时返回入口文档。完成判据：单元测试覆盖「根路径 → 入口」「前端路由深链 → 入口」「资源命中 → 资源本身」三条。
- [ ] 1.3 实现 MIME 映射：按嵌入资源扩展名给出内容类型，覆盖前端产物实际出现的类型（html/js/css/json/图片/字体）。完成判据：单元测试逐类型断言内容类型，且断言不会把脚本/样式标成通用二进制类型。
- [ ] 1.4 实现安全响应头：静态响应带 `Content-Security-Policy`（取值不宽于 `docs/FRONTEND_DESIGN.md` §4.5 基线）与既有接入层的安全头；CSP 必须由响应头下发。完成判据：单元测试断言入口与资源响应都含 CSP，且断言取值不含允许任意来源脚本或任意连接来源的指令。
- [ ] 1.5 明确拒绝非读取方法与越界请求：对静态路径的非 GET 方法返回明确拒绝状态，MUST NOT 返回入口文档冒充成功。完成判据：单元测试断言非 GET 得到明确拒绝而非 200。
- [ ] 1.6 改写既有断言：`net/tests.rs` 中「`/` 必须 404」的用例按新语义更新为「根路径返回入口文档」，并在用例内写明改写理由（该断言描述的是 `server::sync` 缺席期的行为，现已改变）；同时确认 `/unknown` 在单页回退语义下的期望被显式判定而非默认沿用。完成判据：`cargo test -p server` 全绿且改写的用例带理由注释。

## 2. 嵌入与构建期关闭（WP2）

- [ ] 2.1 引入嵌入依赖并在报告中登记选型理由：必要性、维护状态、许可证、平台支持（`AGENTS.md` §8）。完成判据：`crates/server/Cargo.toml` 与根 `Cargo.toml` 的改动就位；`npm run check:boundaries` 断言依赖方向未变。
- [ ] 2.2 实现嵌入资源表：以前端构建产物目录为输入，提供「按路径查资源」「枚举资源」「取得构建版本」三项能力；MIME 由扩展名映射（与 WP1 的映射表同源，不得有两份）。完成判据：单元测试断言资源可查、未知路径未命中、版本条目可读。
