## Purpose

定义 Harness 实际暴露的子 Agent 身份、父子会话及多次委派之间的关系，使子会话作为父历史中的步骤点击展开并在重启后保持可靠关联，同时明确仅有工具载荷或摘要时无法证明的内部执行边界。

## ADDED Requirements

### Requirement: 可靠身份才建立子会话
系统 SHALL 只根据可靠原生身份与来源范围建立子会话及父子关联，分别保存参与者身份、会话和委派；仅暴露工具调用、摘要或结果时 MUST 保留原结构并标记限制，不伪造子会话。

#### Scenario: 仅有工具结果
- **WHEN** Harness只发出委派工具调用及结果而无稳定子会话身份
- **THEN** 父历史保留工具结构和实际输入/结果并标记缺少子历史，不生成可展开完整历史的虚构子会话

### Requirement: 多次委派不等于多个身份
系统 SHALL 保留同一参与者的多次委派与各自来源关联，不因显示名相同合并不同身份，也不因重复委派拆分同一可靠身份。

#### Scenario: 同子身份多次委派
- **WHEN** 同一可靠子身份收到两次不同委派
- **THEN** 两次委派独立保留并关联同一身份，不覆盖第一次

### Requirement: 父步骤内展开子会话
系统 SHALL 将有可靠关联的子会话作为父轮次中的委派步骤，点击后在步骤内展开子历史并按前端传入轮数正序分页，默认10轮；父会话按前端参数倒序分页，默认10轮，子分页不增加父页轮次或改变父页边界。父步骤位置由父条目决定，MUST 不将父子正文混排或声明跨会话全局执行顺序。

#### Scenario: 父子交替输出
- **WHEN** 父子会话并行产生内容
- **THEN** 父步骤保持其父会话位置，子内容仅在所属步骤内按子顺序更新和正序分页，父分页仍按指定轮数倒序读取，不受子分页参数及进度影响

#### Scenario: 展开区域自定义正序分页
- **WHEN** 子会话有25轮，前端在父步骤内传入每页5轮后继续翻页
- **THEN** 依次正序读取第1至5轮、第6至10轮等，省略轮数时默认10轮，不跳转子页或改变父分页位置

#### Scenario: 多次委派展开同一子会话
- **WHEN** 两个不同父委派步骤可靠关联同一子会话，用户分别点击展开
- **THEN** 两个父步骤及其来源引用分别保留，展开沿用同一可靠子身份，不复制子历史作为新会话，也不将多个步骤合并；无法证明每次委派的子内容范围时明确标注，不猜测裁剪

#### Scenario: 嵌套子步骤
- **WHEN** 已展开的子历史包含可靠关联的下一层子会话步骤
- **THEN** 用户可在该步骤内继续展开，保持逐层来源和各层内部顺序，不伪造全局时间线或预读整棵树

#### Scenario: 子步骤展开受限
- **WHEN** 用户点击子步骤但子目标权限不足、已撤销或可靠关联已不可用
- **THEN** 保留父步骤及其有权读取的摘要，明确展示限制且不返回子正文，不将父历史权限视为子目标访问授权

### Requirement: 重启一致与支持边界
系统 SHALL 持久化可靠身份、关系及已观察子历史，重启后保持关联；分别记录三款Harness真实暴露范围，未暴露或缺失内容 MUST 明确标识。

#### Scenario: 重启后浏览子会话
- **WHEN** 已保存子身份与历史后节点重启
- **THEN** 父步骤仍关联原子会话且可点击展开已保存历史，历史来源于平台，不依赖恢复Harness
