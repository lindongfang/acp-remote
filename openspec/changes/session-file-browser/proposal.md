# Proposal

## Why

当前对话页右栏只展示会话改动事件，无法查找工作目录内其他文件，也无法检查 Git 未提交状态。用户希望把「变更文件」扩展为「文件」，从三种来源选择文件，并在中间对话区阅读内容或差异。

## What Changes

- 保留原始诉求：「变更文件，替换为文件；文件下方有全部文件、Git 未提交文件、当前会话变更文件三个选项」。采用名称「全部文件 / Git 变更 / 会话变更」，默认会话变更。
- 全部文件逐层浏览当前会话工作目录，默认显示隐藏与 Git 忽略文件，但始终隐藏 `.git`；按钮支持隐藏忽略文件。
- Git 变更包括已暂存、未暂存和未跟踪文件，默认展示相对上次提交的合并差异。不在仓库中时明确说明。
- 会话变更按文件合并，只包含当前会话 Agent 的修改，可按时间查看历次记录，不拼接累计差异。
- 点击文件替换中间对话区为只读文件内容、Git 差异或会话修改记录；右上角关闭恢复对话、滚动位置与草稿。点击另一个文件直接替换，不增加页签，不停止 Agent。窄屏关闭返回文件列表并恢复位置。
- 文本与常见图片可预览，其他二进制可下载；大文件限制预览并明确提示。进入视图、手动刷新与会话文件事件触发刷新，不持续监控磁盘。
- 新增只读 Sync 查询与协商能力，限定本节点直接管理的会话工作目录；目录外链接只展示不可打开。远程导入会话仍展示已有会话变更，另外两项明确不支持。

硬约束：不改变 ACP 原生语义或解析原文补造差异；不扩展设备授权维度；不突破工作目录；不覆盖工作区已有在途修改。

非目标：文件编辑、提交/暂存/回滚 Git、累计会话差异、多个文件页签、持续文件监听、跨节点文件协议、任意主机路径浏览、正文持久缓存。

成功判据：三种来源可准确区分；本地文件与 Git 状态可由真实 Daemon 查询；开关文件不丢对话状态、不终止 Agent；窄屏可返回；越界链接、超限、非 Git 与远程不支持均明确反馈；合同、Rust、前端检查及分层 E2E 通过。

## Capabilities

### New Capabilities

- `sync-session-files`: 以会话为范围的本机文件枚举、分块读取/下载与 Git 状态/差异只读查询，含认证、协商、路径边界与资源上限。

### Modified Capabilities

- `pwa-web-client`: 文件栏三种来源、按文件归并的会话改动、中间只读查看与关闭恢复、宽窄屏交互。

## Impact

- Rust：`core` 的领域类型/端口/用例、`sync-protocol` 的查询 DTO、`server::sync` 的门控与映射、本机文件与 Git 出站实现及 `app` 组合根。保持现有依赖方向和 core 依赖闭包，不修改 Node Link。
- TypeScript：协议解码、客户端应用服务与状态机、会话模型、文件栏、中间查看器、平台下载适配和宽窄屏 E2E。
- 合同：命令与 feature 登记、Sync schema/共享 fixture；新增能力通过 feature 协商引入，不改变 `workspace.browse` 只列子目录的既有合同。
- 实现时同步 `INITIAL_DESIGN`、`FRONTEND_DESIGN`、`SYNC_PROTOCOL`、`CORE_PORTS_AND_STORAGE`、`MODULE_ARCHITECTURE`、`SECURITY_DESIGN` 与相关合同资产；若配置/对外路由不变，不引入配置项。无数据库 migration。
- 当前 `conversation-page-prototype-parity` 已显示任务完成但尚未归档，且组件与协议存在大量在途修改；实现以其已检视的最终状态为基线，不能覆盖。本变更在归档时覆盖它的旧文件栏要求，其余呈现规则保留。
