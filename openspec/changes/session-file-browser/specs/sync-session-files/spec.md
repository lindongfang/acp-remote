# Spec Delta

## Purpose

为已认证设备提供当前本机会话工作目录内的只读文件浏览、内容读取与 Git 查询，使客户端能够查看真实文件与未提交差异，同时保证目录边界、资源限制、兼容协商及远程不支持行为明确可验证。

## ADDED Requirements

### Requirement: 会话文件查询的认证与兼容前提

系统 SHALL 通过 Sync 提供 `session.files.list`、`session.files.read`、`session.git.status` 和 `session.git.diff` 四条只读查询，均必须携带会话标识并协商 `core.session-files.v1`。查询 SHALL 同步返回 completed 或 rejected，不产生 mutation 受理或终态事件。系统 MUST 在访问文件系统和启动 Git 前验证设备认证、撤销状态、feature 与会话来源，不新增设备授权维度。

#### Scenario: 未协商能力

- **WHEN** 已认证连接未协商该 feature 而调用任一新增查询
- **THEN** 返回 `protocol.feature_required`，不访问文件系统、不启动 Git

#### Scenario: 认证失效

- **WHEN** 未认证或已撤销设备调用文件查询
- **THEN** 按既有认证规则拒绝，不读取文件或仓库

#### Scenario: 远程会话不被映射成本地目录

- **WHEN** 目标会话为 imported 会话
- **THEN** 返回 `capability.unsupported_by_broker`，不访问 Access 本机文件系统，不向 Owner 转发新增查询

#### Scenario: 查询没有异步终态

- **WHEN** 一次合法查询完成
- **THEN** 只返回该 request 的 completed 结果且 `terminalEventId` 为 null，不生成 command terminal event

### Requirement: 查询以会话实际工作目录为根

系统 SHALL 从目标会话的实际运行目录确定根，不依赖是否存在目录登记归属。请求 SHALL 只接受根内相对路径，不允许客户端指定根、绝对路径、父级引用或任意 Git 参数。浏览、读取、下载与 Git 结果 MUST 限定在该根内；根不存在或不可读时明确失败，不回退其他目录。`.git` 管理条目及其内容 MUST 隐藏并拒绝直接读取。

#### Scenario: 未分组会话仍使用实际目录

- **WHEN** 本机会话没有目录登记归属但存在实际运行目录
- **THEN** 查询仍以该运行目录为根，而不是返回主机根或禁用所有查询

#### Scenario: 非法路径在读取前拒绝

- **WHEN** 请求含绝对路径、`..`、NUL 或隐藏的 `.git` 管理路径
- **THEN** 请求被明确拒绝，不读取目标内容，不回显主机敏感绝对路径

#### Scenario: 工作目录失效

- **WHEN** 会话工作目录已被删除或不可读
- **THEN** 返回明确不可用，不能显示其他目录或用空列表冒充成功

### Requirement: 链接不得突破工作目录

系统 SHALL 展示目录内的符号链接或 Windows junction 等链接条目；目标在根外、失效或无法安全确认时 SHALL 标记不可打开，不返回其目标内容或根外路径。目录内链接可浏览但 MUST 防止循环。系统 MUST 防止校验后链接被替换导致越界读取，且只读取普通文件，不打开命名管道、设备或套接字。

#### Scenario: 根外文件与目录链接

- **WHEN** 文件列表中存在指向根外的文件链接或目录链接
- **THEN** 条目仍可见但不可打开，直接构造读取请求也不能取得目标字节

#### Scenario: 链接在校验期间被替换

- **WHEN** 目标在验证和实际打开之间被替换为根外链接
- **THEN** 读取失败或仍只取得根内对象，不能泄漏根外内容

#### Scenario: 特殊文件不阻塞读取

- **WHEN** 请求目标为命名管道、设备、套接字或循环链接
- **THEN** 明确返回不可打开，不无限等待或持续遍历

### Requirement: 文件浏览与忽略过滤

文件枚举 SHALL 返回指定相对目录的直接子项，区分文件、目录、链接及不可打开条目，采用确定排序与有界分页。默认 SHALL 包含隐藏、系统属性与 Git 忽略文件，但排除 `.git`；开启忽略过滤后 SHALL 按 Git 有效忽略规则过滤。非 Git 目录 SHALL 明确返回非仓库状态，不将所有文件误判为被忽略。现有 `workspace.browse` 合同 MUST 不变。

#### Scenario: 默认显示被忽略文件

- **WHEN** 目录含 `.env`、普通文件、被忽略的依赖目录与 `.git`
- **THEN** 前三类默认可见，`.git` 不可见；开启过滤后只隐藏符合忽略规则的项

#### Scenario: Git worktree 的管理文件

- **WHEN** `.git` 是指向仓库管理目录的文件而不是目录
- **THEN** 同样隐藏且不能通过文件读取接口读取

#### Scenario: 条目超过一页

- **WHEN** 当前目录条目超过一页上限
- **THEN** 返回有界结果与继续读取标记，客户端能继续获取，不能静默当作已列完

### Requirement: 文件内容分块读取与下载

内容读取 SHALL 返回文件类型、字节大小、内容版本和有界字节块，以支持文本、图片及用户主动下载。连续读取 SHALL 绑定同一内容版本，文件发生变化时明确要求重新读取，不拼接不同时刻内容。完整下载 MUST 复用已认证连接，不生成长期 bearer 链接，不绕过消息上限；取消、断连或设备撤销后 MUST 停止后续读取。

#### Scenario: 同一版本分块下载

- **WHEN** 用户下载超过单块上限的普通文件
- **THEN** 客户端按顺序取得同一版本的有界字节块，最终字节与文件一致，内存与单消息占用有界

#### Scenario: 文件在下载期间改变

- **WHEN** 后续块读取时文件版本已变化
- **THEN** 明确失败并提示重新下载，不拼接两个版本的内容

#### Scenario: 下载中撤销设备

- **WHEN** 下载尚未完成而设备被撤销
- **THEN** 后续块被拒绝，客户端不能继续取得内容

### Requirement: Git 状态与合并差异

Git 查询 SHALL 仅覆盖当前会话根内文件，状态包含已暂存、未暂存与未跟踪文件，差异默认比较 HEAD 与当前工作树，不能把暂存和未暂存差异重复相加。新文件 SHALL 按全量新增、删除文件按原内容删除呈现；尚无提交时按空基准比较。冲突、二进制和超限差异 SHALL 明确标识，不能伪装为空差异。查询 MUST 不修改索引、文件、仓库配置或运行仓库自定义命令。

#### Scenario: 暂存后继续修改

- **WHEN** 文件既有已暂存修改又有未暂存修改
- **THEN** 列表只出现一个文件，差异比较 HEAD 与当前内容，不重复累计行数

#### Scenario: 仓库首次提交前

- **WHEN** 仓库尚无 HEAD 且存在文件
- **THEN** 以空基准展示新增，不因没有 HEAD 将整个能力判为失败

#### Scenario: 子目录会话

- **WHEN** 会话根是仓库的子目录，仓库其他位置也有改动
- **THEN** 只返回会话根内改动，不返回根外文件内容或根外路径

#### Scenario: 非仓库与 Git 缺失

- **WHEN** 目录不是 Git 仓库，或本机 Git 不可用
- **THEN** 分别明确表示非仓库或 Git 查询不可用，不能都返回空列表冒充干净仓库

#### Scenario: 仓库含外部差异工具配置

- **WHEN** 仓库配置了 external diff、textconv、hook 或 fsmonitor
- **THEN** 查询不运行这些仓库指定的命令，不因查看文件而执行任意程序

### Requirement: 查询资源限制与无持久化副作用

系统 SHALL 对路径、页大小、字节块、差异、并发和查询耗时设置明确上限，遵守现有 Sync 消息大小与设备限流规则。超限 SHALL 返回分页、明确截断或结构化失败，不伪装完整。文件字节、Git 差异与下载中间块 MUST 不写入普通日志、会话事件日志或客户端持久缓存；查询 MUST 不改变会话、目录登记或 Git 状态。

#### Scenario: 超大或超慢结果

- **WHEN** 结果超过预览预算或 Git 查询超时
- **THEN** 给出明确截断/不可用说明，取消相关任务并清理子进程，其他会话与连接继续工作

#### Scenario: 查询不改变事实状态

- **WHEN** 用户浏览、预览、下载文件和查看 Git 差异
- **THEN** 查询前后的目录登记、会话日志、Git 索引及工作树不因这些查询发生变化，持久缓存与日志不含取得的文件正文
