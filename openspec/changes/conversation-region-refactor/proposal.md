## Why

对话页的临时占位行、滚动位置记录和悬浮按钮跨区域定位造成阅读跳动；输入区需要按用户提供的参考图重新布局。

## What Changes

- 固定会话头、独立对话区和输入区；保留双击标题编辑。
- 底部跟随实际内容增长，上读持续记录阅读锚点；隐藏页面不覆盖位置。
- 对话区内部显示回到底部及跨越顶部的展开块快捷收起入口。
- 重排输入栏，增加既有配置来源的思考设置。
- 移除误用的节点 Agent 目录；子 Agent 存活摘要的协议扩展待用户确认。

### New Capabilities

### Modified Capabilities

## Impact

仅修改客户端组件、设置展示模型、验证和前端文档。当前不改变 wire（网络消息格式）、授权或模块依赖。子 Agent 完整功能未宣称已实现。
