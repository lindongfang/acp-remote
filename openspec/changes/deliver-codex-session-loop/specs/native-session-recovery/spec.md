## Purpose

定义平台会话与 Harness 原生会话的绑定、正常释放和按需恢复，使平台历史始终可独立查看，后续执行则依赖原生上下文；明确恢复失败、历史重放和外部副作用的边界，避免伪造上下文连续或从中断指令续跑。

## ADDED Requirements

### Requirement: 原生绑定与按需恢复
系统 SHALL 保存原生会话标识、所属 Harness 原生范围和必要恢复参数；历史查看不启动 Harness，继续输入前必须成功恢复原绑定，不向新会话灌入平台历史代替恢复。

#### Scenario: 原生状态缺失
- **WHEN** 平台历史存在但原生会话无法恢复
- **THEN** 历史仍可查看，继续输入明确失败，不静默新建替代会话

### Requirement: 正常释放确认
系统 SHALL 在释放时阻止新的相关操作，协调已有工作、刷新缓存并按实际能力释放资源；只有确认释放成功才显示空闲。保存或释放失败 MUST 明确失败，不遗留无人管理任务。

#### Scenario: 释放时保存失败
- **WHEN** 尚有未保存内容且刷新失败
- **THEN** 释放操作报告失败并保留资源管理责任，不返回正常释放成功

### Requirement: 重放隔离与异常事实
系统 SHALL 优先无重放恢复；必须重放时按可靠来源身份隔离旧历史和新输出，不按内容相同去重。恢复 MUST 不宣称工具、审批或子 Agent 自动从原指令位置继续。

#### Scenario: 恢复重放旧消息
- **WHEN** 恢复路径再次发出旧条目
- **THEN** 旧条目不成为新回复；无法可靠关联时报告限制并阻止宣称无损恢复
