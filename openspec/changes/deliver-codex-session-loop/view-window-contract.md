# 有界视图内存窗口子阶段

本文件细化implementation-contract §7的内存容器；行为权威仍为structured-history spec。它不签发读取权限、不把协议消息解释成执行结果，也不实现ACP结构合并、页面轮次或WSS。编码前须独立tester定义及reviewer检查；通过本子阶段不等于任务3.2完成。

## 身份与范围

窗口按NativeSessionKey和ResourceEpoch绑定节点资源，另有不复用的读取代际。开始新重放须在同目标owner中生成新代际并重建窗口；旧代际写入/读取句柄不能更新新视图。完成、失败及淘汰分开：完成只接受所属读取的owner显式证据，容器自身不从idle或RPC形状推断完成；失败保持未完整原因。连接换代或实际释放使句柄无效，浏览器断开不操作此容器。

句柄还绑定当前容器实例，不能从另一个容器复用相同局部序号；每次begin生成checked单调新序号。同目标已有Reading时begin返回Busy，由owner显式结束/失效原读取后才能重建。已结束视图begin时立即撤下旧窗口，旧句柄失效；若新窗口预留失败则本次没有可用新窗口，不把旧视图回滚成最新。已取得旧快照仍明确携带旧代际。读取状态为Reading/Finished/Incomplete(reason)，一旦失败不因随后完成回报自行清除原因；只有新begin重建可重新同步。Finished仅表示上层确认读取完成，只有同时无淘汰及无缺失才可声明当前重放完整。

每条目有本代际单调临时位置、可选可靠来源键及不可信结构字节。来源键须由版本适配器根据实际结构身份提供，最多4096字节且分命名空间；禁止按正文/哈希/时间相近建立键。容器不解析字节、不降为文本、不执行资源引用。未知结构按原始条目存储。无可靠键的新条目只分配临时位置，不与其他条目去重。

同代际可靠键替换保持首次位置；上层须提供已按协议合并且保真当前结构的完整替换，容器不深合并JSON或把chunk当替换。更新无法对应仍保留的条目时明确返回MissingItem，不猜测追加；消费层保留衔接限制或重新读取。新重放不跨代际保留键索引，当前子阶段不宣称跨加载稳定身份或完整轮次分页。

## 预算与租约

生产预算沿§7：每目标16MiB/4096条，节点128MiB/32768条。最多64个存活的窗口预算身份是内部保护参数，不替代会话资源容量规则。字节预算计入数据、来源键、条目固定开销以及快照容器/每个引用的保守固定开销；条数预算同时计入存活条目和快照引用。所有算术checked，无溢出回绕；测试可显式缩小预算。

目标预算身份按NativeSessionKey分配，跨读取代际、load/connection/runtime换代的旧快照与新窗口合并计费；目标只有一个当前窗口。旧窗口释放后，身份仍保留到所有旧数据/快照租约Drop，才可回收64身份名额；不能通过换代或重复释放再开得到新的16MiB预算。无租约且无窗口的空身份可即时回收。实例拥有根预算8192字节（含64个固定槽及其索引）；每目标身份额外1024字节+原生ID UTF-8长度；每当前窗口1024字节；每存活条目512字节+可靠键长度+结构字节长度；每快照256字节+每引用64字节。根开销计节点，其余同时计目标及节点。原生ID/键最多4096字节；键命名空间为闭合枚举或受同一长度限制，不能隐藏另一个无限字符串。

条目用逐节点释放的有界容器、可靠键通过最多4096条线性查找，不保留全历史键集合；固定槽或未缩减的容器capacity须已在以上保守常量中计费。快照引用使用精确长度的boxed slice，候选分配在计费后进行；空快照同样收256字节。实现如需超出上述布局的额外capacity或索引，必须追加计费而非假设常量包揽。淘汰事实仅保留有界位置水位与计数，不累积区间或tombstone。

存储字节仅由有预算的不可变对象拥有；公开快照持有只读引用租约，不暴露可无计费clone的Arc。移除窗口/条目不能使仍被快照持有的字节退账；最后引用Drop时退回所属目标及节点预算。替换的候选与旧数据同时存活期间都计费。快照本身不得Clone，快照元数据及引用在创建前先计费，失败零新租约；快照只提供借用的条目字节及来源键。API调用者主动复制数据属于外层独立预算，不能直接接成无界响应队列。

新增条目在预算不足时可淘汰本窗口最早条目并重试；只保留最近窗口，明确最早仍保留位置/曾淘汰范围。被租约持有的数据仍占预算，不能靠反复淘汰绕过；无法容纳新条目则返回Capacity，标记当前读取未完整。其他目标内容不被本子阶段隐式清除，节点总量满时明确拒绝而非无界分配。单条连保守开销超过目标预算直接拒绝。淘汰、快照失败、容量失败都只改变展示状态，不调用取消/关闭/管理事务。

新增与替换为不同API：insert可带此前未见的可靠键，若当前已有相同键则Conflict而非重复条目；replace只匹配当前保留键，保持原位置，MissingItem不新增。已淘汰键不长期保存，也不接受上层把迟到patch冒充insert；完整来源新实体与既有实体更新由版本适配器区分。替换需同时保留旧数据与候选的预算，不能先释放旧数据再尝试以致失败丢旧视图；替换预算不足保留原条目并报告未完整，不隐式淘汰该条目或其他条目。

显式刷新开始新读取时立即失效旧读取句柄，旧快照只代表原代际的旧视图。快照记录资源/读取代际、读取状态、保留窗口、淘汰事实，不把“完成传输且存在缺失窗口”称完整历史。首次快照立即包含已保留在途条目，不等待新通知。快照无永久存储和序列化副作用；不读取旧聊天表、命令、审批或私有文件。

## 后续接线边界

当前模块是节点内部纯容器，NativeSessionKey/ResourceEpoch不构成客户端权限。实际入口每次取得快照及每个引用块交付仍须按implementation-contract §9在client_gate内检查当前actor/代数、目标权限、读取代际和撤销。完整结构适配器须先固定各版本message/chunk/tool/metadata的替换与追加规则，再接本容器；不得把这个低层API的存在宣称为通用重放已完成。

独立验收应覆盖：同源不同目标/同target不同连接隔离，旧代际拒绝，首开已有在途输出，同键替换原位置，无键不猜测合并，失去原条目不追加，流式淘汰范围，单条超限、全局/目标字节与条数、checked溢出、引用持有时淘汰/换代/释放仍计费、最后Drop退账及预算身份回收，快照预算失败无泄漏，失败/未完整与完成分开、淘汰和读失败零执行动作。以上仅为CL-006/012/023/024/049–052/ARCH共享视图的L3子范围，完整L5/L6仍待实际节点及协议接线。
