# 当前实施合同：Q-001

2026-10-31。本轮行为权威为八份specs及design。此前签名期限、时钟水位、重放强制门槛、正文预算和派发再验原actor的细节已被取代；现有代码、schema4和历史测试不因本文自动升级。本文件为新接线边界，准确DTO/DDL及版本算法仍须在实施前冻结并独立检视。

## 1. 分层与受理

domain分别表达队列项、输入提交、平台Run、原生活动、审批与资源；application编排，协议适配不写SQL。节点认证并在提交时校验本次权限、目标、内容，登记稳定不透明请求ID及绑定状态。取消额外每动作JWS、输入24小时截止、time_floor持久水位和回退锁定；现有字段先保留，不自动删库。

同ID重试只返回原事实，同ID异内容冲突；未知旧登记ID拒绝，不能走“无记录即新输入”。编辑是独立命令，保持队列项及位置，冻结新内容版本和编辑授权。一次受理授权供节点后续执行，不在派发时复核原actor；当前读取和新的管理命令仍走认证及撤销边界。

## 2. 节点队列与串行派发

每NativeSessionKey一个共享队列、一个派发所有者；最多三个未发送项，运行及待插入单独表示，不在入队时占据唯一活动Run。节点确定入队、编辑、取消和取出顺序；发送先于取消/编辑则返回已发送失败，不自动中断。

队列无TTL、正文仅内存，浏览器变化保留、节点重启不恢复也不专门提示；必要去重和发送事实独立保存。不另设正文大小、输出缓存及视图容量上限，不借旧条目/快照/引用预算间接限制。控制通道本身的既有非正文规则仍保持。

派发仅消费当前有效队列版本及目标资源，不重验原提交者。前台未结束、active/unknown或待插入时等待；资源失效暂停核验，不把零发送标为交付未知。可靠成功后下一条，可靠失败挂起旧项，新输入优先，旧项须点击继续恢复；立即发送只选现有项，先确认中断完成，其他顺序不变，满队列新草稿不增第四项。

## 3. 协议所有者与取消

reader持续接收，不能等待命令持有的目标或actor锁。队列协调仅保护状态先后，长load/replay/prompt、SQL及用户选择不占会话互斥。写意图和事件有明确所有者、顺序、取消及关闭；取消未发意图后不能残留脱离调用的首次写任务。实际发送前核对取消/编辑版本与资源代际，不以旧actor gate控制。

协议写成功仅传输事实。确定零发送可继续；可能接收未知不重发；浏览器重试查询节点。区分写入、插入和执行等待；不要给长模型运行套首次写超时。实际等待预算按接口用途冻结，旧统一10/5/2秒不是本轮产品要求。

## 4. v1/v2完成和恢复参数

按当前协商版核实官方schema，不按厂商固定。v1 prompt终态与v2 messageId插入不同；v2保留早到活动/终态直至迟到响应协调，不能要求新idle。WorkToken只作内部围栏，不证明原生归属；关联不足保留未知，核验或收敛旧资源后按真实状态放行，不编造成功。

同目标在途恢复/重放须协调；current-state快照不产生新Run完成。缺重放支持当前连接模式，不阻止其他实际能力。恢复/重放使用可信已授权的完整有效Client配置，含协商支持的额外工作根；不把mcpServers=[]或省略根当保持不变。参数未知说明影响并限制相应路径，不私读配置。

## 5. 审批与管理故障

真实审批来自有效Connection的待答复请求，RPC标量类型和原广告保留，Run可选。未知主题/选项提示采用通用安全展示并允许人工选择原optionId，不自动批准；结构错误、伪造来源或选项不在列表仍拒绝。

受理决定时校验操作者和真实请求；唯一决定可靠保存后由节点交付，原审批者离线/撤销不重验。交付仍核对原请求及连接有效性；失效抑制允许，原决定与实际安全响应分别记。可能发送后不补发。数据库故障不能生成允许，也不能无限阻挡可验证安全结束。

必要去重/派发/批准/资源事实失败时停止相关新动作，附加审计失败或满额仅告警，不伪填结果。关闭事实与未保存范围分开，未协调资源账本不返还名额。取消/安全关闭须有当前目标依据，不强杀共享实例其他会话。

## 6. 时间、WSS及验证

以节点时间记录，用节点处理顺序排队；单调计时处理等待，系统校时不暂停或过期输入。其他认证期限独立遵循原合同。复用既有WSS认证，增加队列查询/编辑/取消/优先发送/失败继续等封闭动作，具体DTO在接线前固定；不恢复旧正文持久化接口。

正文和视图不加平台容量封顶，不把旧解析、正文分块或租约预算称ACP标准；真实失败报告来源。结构渲染、URL/文件授权、主动内容隔离仍沿structured-history。现有认证控制帧规则不自动变更。
