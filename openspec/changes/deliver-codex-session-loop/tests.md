### CL-058 新连接优先高版并如实呈现合法协商结果

- 用例级别：L5
- 操作步骤：在节点协议合同入口准备平台 H/L 均已实现并验证的条件，分别提供可选 H 的高低兼容对端、有可靠依据表明 H 无共同支持且规范允许 L 的对端，以及合法选择 L 但未提供原因的对端；记录发起版本、实际选择、可证明的依据和初始化次数。保持旧报告/上次缓存仅为 L，变更 Harness 名称并令当前程序无新版实测报告；对 H 分支选取一项该版已实现且协商允许、低版无法同等表达的能力/结构按对应合同验证，并发送未知或未实现能力作对照。另覆盖对端支持 U 加 H、仅支持无共同版本的 U，以及初始化网络超时/认证失败。
- 预期结果：每个新连接先按最高已实现并验证的 H 规范协商；可用 H 时选 H 并保留其实际能力与结构语义，不因旧报告/缓存、厂商名或缺程序新版报告固定 L，也不将 H 压为低版交集。合法低版结果遵守规范：有依据时展示依据，无原因时分别展示发起 H、选择 L 和原因未提供，不编造对端仅支持 L、不反复初始化强制升版。U 不冒充平台支持，无共同已实现版本明确拒绝；网络/认证错误不被当作 H 不支持，不自动降版或用副作用试探，未知/未实现能力仍明确处理，程序真实证据状态单独保留。

### CL-059 重连重新优先且高版失败不降版重发

- 预期结果：有效旧连接不热切版本，新连接重新优先 H，不被旧 L 缓存或旧报告固定；按新协商绑定能力，但不更换已恢复的原生会话身份。H 业务失败/超时按实际失败或未知处理，缺必需能力按现有准入报告缺口，不自动切 L、启动低版连接重发或绕过重放门禁；已受理旧请求仅返回原事实，旧审批不跨代际交付。协商、重放或连接恢复本身均不授权重复输入、审批或删除副作用。

- 操作步骤：用已准入协议合同连续重放远大于视图预算的历史，混合文字、思考、工具更新、原始扩展字段及大量小条目元数据，来源具有可证明轮次与顺序但无原生分页。设置慢订阅和并发页面请求，记录累计传输、正文/元数据/单帧解析缓冲/在途响应/页缓存的峰值及淘汰窗口，再交付协议规定的重放完成事实。以公开预算及实现观测入口判定；未提供预算或观测入口记未执行。
- 预期结果：允许总传输随全历史增长，共用协议流式重建视图，不因缺原生分页拒绝；每类保留资源均受对应预算限制，不用无界元数据或在途队列隐藏增长。结构、来源顺序和轮次保留；完成前只标部分视图，完成后仍如实说明已淘汰范围，不宣称全部历史都在本地，不写永久聊天档案或把页轮数当总传输上限。

### CL-050 部分中断解析失败及超预算不伪完整

- 用例级别：L5
- 操作步骤：在重放完成前分别中断读取、返回非法结构、发送单个条目超过公开帧或视图条目预算；另取消尚未完成的查看读取。观察页面完整性、错误、重放代际及原生派发；在 Harness 连接仍有效的分支保留正在运行的任务和有效审批，对照连接本身已失效的分支。
- 预期结果：错误或丢失部分明确报告未完整及原因，不返回伪完整历史/成功页、不自动重发输入；展示失败或取消读取本身不取消原生任务及仍有效审批。连接失效另按真实代际失效审批并保留未知执行/资源责任，不能把显示故障与连接事实混为一谈。

### CL-051 无跨加载稳定标识时重建代际而不按正文去重

- 用例级别：L5
- 操作步骤：让标准重放只提供本次加载内的可靠顺序及临时位置，历史内有两条正文完全相同的不同条目；两客户端并发查看同一目标，记录在途重放与加载归属。完成后发起新重放代际并改变临时位置，延迟返回旧响应，期间加入有可靠来源关联及无法证明关联的实时输出。
- 预期结果：同目标在途重放协调，不建立相互覆盖的并行加载；可按本次重放形成临时视图，但不冒称跨加载稳定标识。新代际重建并失效旧读取，旧响应不覆盖，重复正文不合并，历史不追加为新回复；历史与实时不能可靠关联时明确限制，不猜测去重。

### CL-052 重放完成不代替前台终态或恢复授权

- 用例级别：L5
- 操作步骤：在已具标准重放能力的连接上显式选择一次不请求重放的上下文恢复，检查历史同步标识；随后单独完成历史重放。在同目标已有未终态前台执行、取消已发送但终态未到及真实有效审批的窗口完成重放，再由两客户端提交普通输入，并尝试操作重放中的旧审批内容。
- 预期结果：无重放恢复只证明所报告的上下文结果，需要历史时另行协调重放；重放完成只结束该次读取，不创建新 Run、不判定旧 Run 完成、不解除前台互斥或宣布取消完成。旧审批不会因历史重放复活，当前有效审批按真实操作上下文处理，恢复或重放都不自动发送新输入。

### CL-053 重连失去重放能力保留旧事实与资源责任

- 用例级别：L5
- 操作步骤：在准入连接已有受理命令、结果未知执行和资源所有者后，断开并令新连接协商出无标准重放能力；尝试新创建、输入、恢复、接管，并重试原命令。核对旧审批代际、已拥有的任务/进程、关闭协调、其他符合条件接入及原生数据；不把此次能力变化当自动回滚授权。
- 预期结果：停止新产品会话操作且零新派发，原请求仍返回原受理/未知事实而不重发；旧审批因连接代际失效，不自动复用。旧执行和资源继续受管理，按事实协调安全关闭，不假报回滚、不删原生数据、不因厂商名永久禁用其他满足条件的连接。

### CL-054 真实标准重放到有界 Web 视图

- 用例级别：L6
- 操作步骤：固定真实可用 Harness/适配器及实际 ACP 版本，在专用原生根建立含结构化工具内容和可证明轮次的历史，通过真实 Windows 节点与 Web 完成标准全量重放；核对真实重放完成边界、原生调用、来源顺序、峰值预算、淘汰窗口及平台分页。优先覆盖无原生分页的真实组合；有第二款符合相同协议条件的真实对端时核对共用路径，否则该跨款真实分支记未执行。保持用户实际配置与数据不变。
- 预期结果：真实重放与平台视图符合当前合同，首次总传输可随历史增长但保留资源有界，页面说明实际范围且无永久聊天档案。程序/协议/能力及真实覆盖分别报告，不以握手、文档或替身补齐第二款或未实现版本的验收。
