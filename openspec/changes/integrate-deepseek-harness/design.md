## Decisions

### 0. 接入配置复用通用 ACP

PV-001：版本优先级统一引用 harness-management 的“优先最高共同可用协议”。同一程序支持多版时，新连接优先最高已实现版本的标准协商，不因旧探测使用低版而固定低版；对端合法低版选择、原因未提供及规范允许的回退如实呈现。不新增 DeepSeek 版本映射或私有探测，高版业务失败不自动降版重发。当前无重放版本仍按原规则不接入，本轮不宣称新版真实兼容或升级本机程序。

运行时操作准入统一引用 harness-management 的平台处理、当前能力和安全条件三项门槛，程序版本实测状态单独展示；本 change 的正式接入验收门禁不转化为终端用户运行时的版本白名单。原生目标、非输入 Run 的加载审批及当前连接视图均沿通用身份和操作模型。

2026-10-30 职责澄清：本 change 的 Harness 专项交付是能力调研、接入配置和实测验收。固定版本只限定证据，不固定运行时 ACP 版本。每次连接由通用 ACP 初始化流程协商并绑定该连接的版本策略及能力；不配置或硬编码“DeepSeek 只能使用某 ACP 版本”，重连后重新协商。下方 list/resume/close 或历史加载的调研结论也只属于原受测范围，不构成厂商名决定的永久能力表。

本项仅负责接入配置与兼容性验收。版本策略、公共客户端、扩展隔离及升级影响分析遵循上游 [通用 ACP 设计](../deliver-codex-session-loop/design.md) 的“通用 ACP 与多版本兼容边界”。启动入口与本机认证引用记录于 app/src/harnesses/deepseek/；该目录不包含厂商协议实现。版本合同和能力夹具复用通用入口，不按厂商名称选择标准方法。v1/v2 仅验证实际可用组合，规范依据、草案/稳定状态与真实结果分别记录，未验证不得声明兼容。

必要能力缺失、语义不兼容、规范无法核实或需要私有桥接时，暂停受影响接入，向用户报告具体版本、缺口、影响、脱敏证据和可选方案，等待用户决定；不自行增加私有实现、重灌历史或降低产品要求。公共客户端违反已核实标准时回到通用闭环修复并重跑受影响回归；产品规则或桥接范围变化仍由用户决策。Web 使用通用能力及错误展示，不建立厂商特有页面流程。

升级先分析程序、协议、扩展、配置及原生存储影响，重新协商并执行受影响复验。旧证据保留为原版本结果，不视为新版本已通过；标准兼容且复验通过时仅更新配置及证据，不强制修改代码。

### 1. 版本探测决定实际调用

调研先确定Windows实际程序、官方发布来源、受测版本/摘要及适配器，在隔离原生根记录握手和真实行为。把 list/resume/close 作为待核验候选而非硬编码事实。运行时接口是否可用取决于当前协商的协议、能力及对应验证状态，不因旧报告永久启用或禁用某个方法；session/load 不能由厂商名称推断支持。恢复和历史端口分开，防止把无重放误解为没有历史。

### 2. 原生历史读取与上下文恢复分开

先按 harness-management 的标准重放门禁判断准入；只有无重放恢复的版本不开放产品会话操作，也不为继续输入加载。未来实际具备标准重放时，共用 structured-history 的协议处理及 history-navigation 的有界视图分页，再分别验证原生上下文恢复。原生状态缺失明确失败，不新建替身、灌历史或解析私有文件。压缩后仅展示原生可重放内容，跨代际不按文字去重。

### 3. 节点长期拥有连接

协议连接归实例管理器而非Web订阅。页面关闭仅移除订阅；连接异常使所有相关审批代际失效，并将无终态Run记为中断或未知。调研的断线清理不能替代Windows资源确认；实例管理器仍检查拥有的Job Object和任务退出，共享实例影响逐会话记录。取消发出不释放前台锁，等待真实完成或异常事实处理。

### 4. 实证矩阵与升级

以程序版本、适配器版本、协议版本、配置根和测试环境形成一组证据，分别记录声明、协商、模拟与真实结果。必须验证跨进程继续上下文、唯一审批、旧审批失效、取消完成、页面断开、连接异常及进程树关闭；支持子身份和历史读取与否单独列出。升级按本设计通用接入原则进行影响分析及复验；旧证据仅适用于原版本，不因版本号变化自动改代码，也不凭版本号相近沿用通过结论。

## Risks / Trade-offs

- [当前发布版无标准重放] → 暂不接入；不以当前连接模式、永久聊天副本或厂商读取器兜底，后续能力变化重新协商和验证。
- [断线清理范围可能跨共享会话] → 真实记录作用域，实例粒度按可证明隔离选择；无法隔离则不承诺单会话独立释放。
- [认证配置含密钥] → 复用本机凭据边界，不写审计、进程命令日志或测试快照。

## Migration Plan

新增接入配置及版本证据，不迁移旧系统数据。先在隔离原生根验证再开放可信Web操作；回滚停止新建，协调现有实例关闭，保留平台管理记录和原生绑定。版本不兼容时拒绝恢复，不能改写原生文件。

## Implementation Gate

固定版本探测、真实合同验证、依赖审查及独立方案检视尚待实施。本设计没有宣称DeepSeek在当前节点已安装或任何真实测试已通过。
