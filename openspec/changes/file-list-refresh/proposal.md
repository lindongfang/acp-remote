## Why

文件栏展示整个工作目录，但目前仅当前会话的文件变更事件触发刷新，容易漏掉同目录其他会话和人工修改。用户确认改用明确的进入、切换、手动、重连与前台触发，并增强按钮反馈。

## What Changes

- 取消 file.changed 触发的列表刷新，保留正文过期提示。
- 进入会话、切换来源、手动刷新、恢复在线和切回前台时读取当前来源。
- 全部文件刷新根目录及已展开子目录；保留分页，刷新回第一页。
- 请求期间旋转高亮、禁重复点击，全部成功短暂勾号；失败保留对应旧列表。
- 不替换正在阅读的正文或 Git 差异，不引入定时轮询、磁盘监听或新协议。

## Capabilities

### New Capabilities

- `file-list-refresh`: 文件列表刷新生命周期与反馈。

### Modified Capabilities

无。

## Impact

客户端 feature、composition、文件栏组件及前端设计文档；协议与服务端不变。
